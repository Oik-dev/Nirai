# Nirai v2 UI

見た目・配置の仕様は本書、共有色は`src/renderer/theme.css`を正本とする。動作と状態の正本は基本設計とHubであり、この文書はUIの表示契約だけを定義する。仕様の記載を実装済みの意味として扱わず、通常会話を含む現在の到達範囲は[README](../README.md)を参照する。

## 海中Worldと共存する面

- Holo・通常Residentとも同じ透過Glass。主会話面の外側一層（TaskModeではDashboard、ChatModeでは通常会話窓）だけが背後のWorldをぼかし、Task欄・会話欄・選択カードでぼかしを重ねない。
- 外枠・余白の下地は22%と薄くし、会話・見出し・Resident表示・操作ボタンなど文字が載る場所へ局所的に下地を足す。広い空白はWorldが見える透過面として保つ。
- 明るい水面でも読める深い青の半透明下地、白系の本文、淡い青緑の選択・フォーカス。色・透明度・文字寸法は`src/renderer/theme.css`をRendererとHoloが共有する。
- HoloのWebContentsView、html/body、主要会話canvasは透明とし、小さいメニュー・履歴サイドバーは文字の重なりを避ける局所的な塗りを持つ。
- 背景の表示場所は`.world`。3D海中WorldとVRMを背面canvasへ描き、描画不能時に同梱静止画を表示する。
- 海は透明な南国の浅瀬を基準とし、白砂、控えめな光の網目（コースティクス）、小さな泡を描く。遠景の薄れ方は50〜60mの見通しを見た目の目安として調整する。水面は不規則な小波の反射・屈折を使う。

## ChatModeと通常会話

- ChatModeはWorldを広く表示し、左下の会話窓からTask外の通常会話を行う画面。狭幅でも会話窓を画面内に収め、Worldを見られる領域を残す。
- 会話窓の初期幅は528pxとし、画面の余白内に収める。上端中央の小さな「───」ハンドルは高さ、右辺は幅、右上の角は幅と高さをドラッグ調整する。左下の位置を固定し、サイズ調整でWorldの視点・Focus・会話先・下書き・読書位置を変えない。画面縮小時は表示サイズを制限し、再拡大時はその起動中に選んだサイズへ戻す。
- 実表示には「会話」の見出し、「広げる」ボタン、参加中Residentの一覧、「Say → この場のみんな」等の冗長な宛先説明を置かない。装飾は用いてよいが、操作や本文を妨げない。
- FocusはChatMode内でキャラクターに注目している状態。キャラクターを左クリックするとその相手へFocusし、UI以外のWorld背景を左クリックすると現在の位置・向きを保って自由視点へ戻る。右ドラッグ、ホイール、会話窓・設定等のUI操作ではFocusを解除しない。
- Focusと自由視点の切替ボタンは置かない。「Worldを見渡す」「Focusを外す」等のボタンは削除する。TaskModeへ戻るナビゲーションと視点リセットは、それぞれ別用途の操作として扱う。
- 会話窓はFocusしても左下から移動しない。会話先の切替には「Say」と、Whisper対応Residentの表示名を使う。選択状態と送信前の入力欄の短いラベルで宛先を識別できるようにする。入力欄ラベルは画面に出さない読み上げ用ラベルでもよい。
- Whisper対応ResidentをFocusした際、入力欄が空の場合だけその相手のWhisperへ切り替える。入力中は宛先と下書きを保ち、カメラだけを切り替える。自由視点へ戻してもWhisperの宛先を維持し、Sayへの変更は会話窓で明示的に選ぶ。
- Sayと各ResidentのWhisperは、会話窓の履歴・下書き・閲覧位置をそれぞれ保つ。表示上の区別は、発言が直接届く相手の違いを示す。受信したResident本人の記憶を分けたり、本人によるSayでの再発言を禁止したりする表示ではない。過去の文章を読んでいるときは、新着で閲覧位置を変えない。直接配信と本人の記憶・再発言の契約は基本設計§13、Personaは§16を参照する。
- 各発言に保存時刻を端末のローカル時刻で`HH:mm`形式で表示する。履歴の復元・再描画で現在時刻に置き換えない。日を跨ぐ履歴にはコンパクトな日付区切りを入れる。
- Masterの吹き出しは右、Residentの吹き出しは左に寄せる。本文はどちらも左揃えとし、長文は会話窓の幅内で折り返す。
- HoloもSayの参加者およびWhisperの宛先として左下会話窓を使う。Focus時の宛先選択は他のResidentと同じ。通常会話は生成中の状態と保存済みの最終本文を表示し、ChatGPT native surfaceは常時重ねない。Resident設定の「ChatGPTを開く」からTaskを作らずログイン・接続確認できる。閉じると設定の起点へ戻る。Task会話は現在のChatGPT native surfaceを維持する。

## World操作とAvatar

- 海中は全方向に見渡せる3D空間。右ドラッグで見回し、WASDで移動、Q/Eで上下、Shiftで加速、ホイールで前後移動する。WASDと右ドラッグの同時操作では、見回した向きと移動を同じ描画周期へ反映する。Worldをクリックして操作を開始し、会話・設定・別Windowへフォーカスが移ったら移動入力を解除する。
- カメラは海底から35cm以上、水面下約45cmまで、中心から水平半径6m以内。Focusも同じ上下・水平境界を守る。初期位置へ戻す視点リセットボタンを常設し、Focus解除用のボタンとしては扱わない。
- Focusでは対象を見続けて周回でき、ホイール／W・Sで90cm〜4.8mの間を接近・後退する。Focusへの移行と自由視点への復帰は上記のクリック操作に従う。World操作中のEscapeも、背景クリックと同じく現在の位置・向きを保って自由視点へ戻る補助手段として利用できる。
- Focus中は頭・首・目を緩やかにカメラへ向ける。胴体を回転させない。頭と首の合計は左右35度・上下22度以内（首の分担は28%）、眼球の入力角は左右20度・上下12度以内。背後へ回り込むと追従を弱めて正面へ戻る。解除時も自然に正面へ戻る。Blinkと髪等の揺れは身体機能として扱い、感情や服装をプログラムが選択しない。
- AvatarはResident設定の「VRMを選択」から設定する。Hubの`resident_avatars`が不変Resident IDとローカルファイル参照の正本。参照だけを保存しモデルは複製しない。VRM 1.0と互換VRM 0.xの自己完結GLBを受け入れ、外部素材参照・ネットワークパス・96 MB超を拒否する。「表示を外す」は関連付けだけを外す。
- Resident設定に、本人が選べる表情・衣装部品・外見項目の数を表示する。標準の感情Expressionのうち実作用があるものと、VRM内のNirai Metadataで有効に公開された選択肢だけを扱う。外見項目は複数部品の表示と変形をまとめて変更できる。衣服の新規生成・別モデルからの移植は含まない。不正なMetadataは該当する切替だけを無効にして知らせる。形式は[avatar-appearance.md](avatar-appearance.md)を参照する。
- 本人の表情選択は約0.25秒で補間し、瞬きや視線はVRM作者の干渉規則に従って両立する。動きを止めている場合は選択状態へ即時反映する。保存と反映確認の契約は基本設計§16.3を参照する。
- キャラクターの位置と大きさは世界内で固定する。Dashboardの開閉・縦長化では表示中心を調整する。カメラとFocusは一時的な表示状態で、Reload時は初期視点へ戻す。
- キャラクターのコースティクスは太陽光に乗る。光が当たる面だけ、砂地と同じ網目が揺れる。初期配置では太陽が背面側にあり、正面は影なので網目は見えず、背面には見える。
- 描画は最大30fps・160万画素を目安に制限し、非表示中は停止する。入力・アニメーション・Hub状態の表示更新は一つの描画周期へまとめ、表示に変化のないHub Snapshotでは再描画を要求しない。「動きを止める」とOSの動きを抑える設定では自動アニメーションを止め、カメラの手動操作を保つ。描画喪失時は静止画へ戻し、Context復旧時に3Dへ戻す。VRMの読込失敗はWorld内で知らせ、設定から選び直せる。

## TaskMode（Task管理）の配置と操作

| 範囲 | 配置 |
| --- | --- |
| 横長・900px超 | 左にDashboard、右にWorld。Dashboard内はTask一覧と会話の左右配置 |
| 縦長または900px以下 | Dashboardを下側へ寄せ、Worldを上側に残す。目安58vh、操作領域の下限430px、画面外へ出ない上限 |
| 760px以下 | 「一覧」「会話へ」で一面ずつ表示。Holoも通常ResidentのTask Chatも同じ切替 |
| 440px以下 | Residentをヘッダーの二段目へ配置 |

設定を開く・Dashboardを格納する・狭幅で一覧を開く際は、既存の表示IPCでHoloを外す。戻す際は新しい表示寸法を決めてから取り付ける。設定、通知、Task操作はnative会話の上に重ねない。表示枠の寸法変更も監視するため、長い通知で見出しの高さが変わっても追従する。

開閉ControlはDashboard側に集約する。展開中はヘッダーの格納ボタンを表示し、ChatModeでは同じ側に「Task」と状態件数をまとめた小さなボタンを表示する。

通常ResidentのTask Chatの下書きはTaskごとに分離して保持する。状態更新時もメッセージ欄、Task操作のフォーカス、展開した成果物、スクロール位置を維持し、過去の文章を読んでいる時は新着によって閲覧位置を変えない。Task外の通常会話の下書きはChatModeの契約に従う。

設定はTabをダイアログ内に保ち、Escapeで閉じて起点へ戻す。失敗通知は確認されるまで保持する。取得できない使用量は「未取得」と表示し、Usage graphは取得済みデータから描画する。

通常Residentの追加・編集では「AIの接続」「接続を確認」「Model」を同じ設定面に置く。接続名とModel一覧はHubの接続情報から表示し、接続確認中・応答中・未接続を区別する。狭幅でも追加・保存ボタンへスクロールして届くようにする。Codex CLIは既存のChatGPTログインを使い、APIキー欄を設けない。

## 表示責務の境界

海の波は`src/renderer/world/waves.js`が持つ24種類の不規則な小波を重ねて作る。[ScottieFox/caustic-volume](https://github.com/ScottieFox/caustic-volume)の波の組み立てを参考にし、帰属は`THIRD_PARTY_NOTICES.md`へ集約する。`caustics.js`は波の高さ・傾きを描画用の画像へ一度計算し、水面表示と光の屈折で共有する。屈折後の光の集まり方も画像へ計算し、海底・Avatarの光の網目と水中の光の筋へ使う。水中の色・透過・散乱は`optics.js`を共有の正本とする。

`holo-dom.mjs`のdecoratorは監査済みのcomposer内面、sidebar実root・上下端、Chat/Work切替の識別を担当する。送信・Stop・scroll guardとは別の責務とし、Native本文、思考、推奨、引用、画像、メニュー、クリック処理はProvider surfaceを利用する。Style変更は監査済み要素へ限定する。

送信準備の案内はnativeの入力欄とアプリ候補の位置だけへ「送信中…」を重ねる。元の要素やMaster下書きは表示制御のために変更せず、既存のアプリ選択・下書き判定・送信経路を使う。会話本文は表示を続け、準備中の入力欄へのクリック・キー入力だけを抑止する。送信後、Stopの出現、Conversation変更、失敗・中止・非表示時には案内を解除する。MainからRendererへ渡す表示状態はTask ID・native面の表示有無・準備／読込の段階だけで、画像を取得・保存・表示しない。

ページ読込でnative面を隠す間は「会話を読み込んでいます…」を表示する。表示不能の理由は読込案内より優先する。Task変更・Dashboard格納では、前の読込やHub取得を待たずnative面を隠し、古い表示要求が後から画面を復活させないようにする。この非表示通知はTaskやTurnの権限を変えない。回答取得fallbackは、同じConversationの生成終了・本文なし・Master下書きなしを再読込の直前にも確認し、生成再開や最終本文の出現時は通常の観測へ戻す。

`holo-skin.css`の変更前には実DOMとcomputed styleを採り、通常本文だけでなくbody portal、sticky/fixed、疑似要素、view transitionと実表示境界を調べる。透明化・背景変更は原因が確認できた要素へ限定する。詳しい監査は[holo-surface-audit.md](holo-surface-audit.md)。

## 検証

`npm run smoke:ui`は通常のHub往復に加え、360×600、620×980、900×600、1500×930、1920×1080の配置、Glassの重複、下書き分離、読書位置、承認・却下のフォーカス、設定のキーボード操作を検証する。ChatModeでは実画面からSay / Whisperを保存し、保存時刻・未接続表示・Focusと下書きの分離・上下/横/角のドラッグと取消・画面縮小後の希望サイズ復元・360 / 620 / 1500px配置を確認する。左右の吹き出し、日付区切りと幅変更後の読書位置は表示用データで確認し、未接続Residentの実応答成功を示さない。`NIRAI_V2_UI_CAPTURE_DIR`指定時は画面を保存する。

`npm run smoke:holo`は模擬Providerで透明canvas、未知面の保持、sidebar/composer、既存の送信・Stop等を検証する。

`npm run smoke:holo:preparation`は独立した非表示・フォーカス不能Window内で、旧／現行のProvider DOMの送信案内、下書き保持、準備中のキー入力抑止、アプリ選択と本文入力、送信後の案内解除を検証する。OSのマウス・キーボード操作や画像保存を行わない。実ChatGPTの目視確認とは分ける。

`smoke:world`は実Electron上でWorldの描画、WASDと右ドラッグの同時操作、UIへのフォーカス移動による入力停止、停止・復旧を検証する。VRMの有無に関係なく360×600・620×980・1500×930と、Dashboard格納時の初期視点・見上げ・反対向き・海底近く・水面近くを撮影し、外観比較に使える。実VRMの表示、クリックFocus、UI・右ドラッグ・ホイールでのFocus保持、背景クリック解除と位置・向きの保持、視線、自己表現、Reload・Hub再起動後の再表示は、`NIRAI_V2_WORLD_SMOKE_AVATAR`でモデルを指定した場合だけ確認する。動くWorld上での実ChatGPT同時運用は未確認であり、模擬ProviderやWorld単独の検証とは別に記録する。
