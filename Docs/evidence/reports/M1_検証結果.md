## 2026-08-29 M1 Stable最終確定

### 判定

- Masterによる継続的な実Electron操作確認と、最終差分に対する再レビューを完了した
- 再レビュー結果は **SAFE**。追加の修正必須事項・インライン指摘なし
- M1のCore / World接続、Chat Session、Say / Whisper、Codex Brain、Private / World Memory、VOICEVOX、LipSync、Resident設定・削除、履歴Delete / Forget分離をStableとして固定する
- Whisper履歴の表示は最終UI調整として、`あなた:` / `Resident名:` の話者名だけを淡い青で表示し、冗長な宛先表記を省略する
- 以後、M1へ新機能を追加せず、複数Resident・複数Brain・resident_chat等はM2として扱う

### 最終レビューで確認した修正

- Whisper履歴が空または短い場合でも、表示領域が埋まるか最古履歴へ到達するまで古いページを自動取得する
- 履歴ページングはtimestampではなくCore発行の不透明な位置カーソルを使い、既存の秒精度履歴でもページ境界の発言を欠落させない
- Avatar読込中にResidentを削除した場合、進行中の読込結果を無効化し、削除済みResidentを後からSceneへ戻さない
- 一時アイコン調査スクリプト等の作業残骸を残さない

### M1で固定する境界

- ResidentはM1では1人まで。Stable時点の初期実Residentは `Lapan`
- BrainはM1ではCodexのみ利用可能
- SayはWorld Memoryへ公開Episodeとして保存する
- Whisperは宛先ResidentのPrivate Memoryだけへ保存し、World Memoryや他Resident Contextへ混ぜない
- 発話の正本はテキスト。VOICEVOX停止・Mute中でもテキスト会話は継続する
- World Memory Retriever / RAG、生活ティック、Task、複数Resident、resident_chatはM1へ含めない

### M2への引継ぎ

M2ではM1の単一Resident制限を段階的に外す。実装順は `Docs/詳細設計/10_AITuberKit分析と実装ブループリント.md` を正とし、最初にResident 2体表示を成立させ、その受入後に3体表示へ進む。
