# Nirai M2 検証結果

本書はM2「社会」のStable受入記録である。現行仕様の正本は `Docs/詳細設計/` 配下を参照する。

## 2026-08-30 M2 Stable最終確定

### 判定

- Masterによる実Electron QAと、最終差分に対する再レビューを完了した
- 最終再レビュー結果は **SAFE**。M2の修正必須事項は残っていない
- M2の複数Resident表示、ResidentごとのBrain / Model設定、Say逐次応答、Global SpeechQueue、resident_chat、会話Formation、公開Episode単一保存、Whisper秘匿、Resident並べ替え、Gemini / Antigravity BrainをStableとして固定する
- 以後、M2へ新機能を追加しない。生活・World Observation・Retriever / RAGはM3、PC上の実作業Agent RuntimeはM4以降として扱う

### 最終実機QA

- 3人会話の `approach / gather / face` を実Electronで確認し、団子状にならず浅いU字Formationへ集まり、身体ごと会話焦点へ向き、会話終了後に元位置へ戻ることを確認した
- 右Resident Sidebarのドラッグ並べ替えが表示中Worldへ即時反映され、再起動後も順序が永続化されることを確認した
- Antigravity background Interactionを手動Stopした際、Google側remote Interactionへcancelを送り停止できることを確認した
- Antigravityへ最新情報を必要とする質問を行い、`google_search` / `url_context`経由で外部情報を参照して回答できることを確認した
- AntigravityのWeb検索QA中に、Gemini Residentが通常 `gemini-3.5-flash-lite` へ戻っていたケースと、Private Whisper履歴に残った古い「Web検索できない」自己認識を切り分けた。誤ったQA履歴はPrivate Memoryから除去し、Antigravity選択時のWeb参照を実機で再確認した

### 最終レビューで閉じた問題

- Codex / Cursor / GeminiのPersonaを現行の役割に合わせて整備した
- Gemini Developer APIの非同期HTTPS処理について、Content-Length、chunked response、途中切断、手動Stop時のremote cancelを確認した
- Antigravityの120秒自動Timeout時にGoogle側background Interactionが残る問題を修正した。取得済みInteraction IDがある場合はremote cancelを一定時間内で試してからTimeout Errorを返す
- 上記自動Timeoutについて、`in_progress`のままTimeoutした場合に `/interactions/{id}/cancel` が呼ばれる回帰テストを追加した
- Avatar入力はVRMへ一本化し、品質再現が不安定だったUnityPackage / FBX自動変換をM2の正規経路から外した
- API KeyはRenderer / Protocol / Logへ出さず、`world/.env`はGit管理外のまま維持した

### M2で固定する境界

- World上の実機表示受入はResident 3体までとする
- resident_chatの会話State Machineは2〜10人を共通規則で扱える構造を維持するが、4人以上の視覚FormationはM2受入範囲外とする
- Say時のBrain呼び出しとTTSは直列化し、複数Residentが無秩序に同時発話しない
- 公開resident_chatはWorld Memoryへ1つのEpisodeとして保存し、Resident別コピーを作らない
- Whisperは宛先ResidentのPrivate Memoryだけへ入り、他Residentの公開会話Contextへ漏らさない
- Claude Driverはモック受入済みだが、Stable時点のLive疎通はサブスクリプション側HTTP 403のため保留とし、従量APIへ自動切替しない
- Gemini / Antigravityは会話用Brainとして扱い、ファイル操作・コード実行等の実作業はM4 Agent Runtimeへ分離する
- Antigravity会話時は `google_search` / `url_context` だけを許可し、remote sandboxのコード実行・filesystemを会話経路へ開放しない

### 次マイルストーンへの引継ぎ

M2で「複数Residentが同じ世界に存在し、公開会話できる」土台を固定した。以後はM2へ機能を逆流させず、生活・長期想起はM3、MasterからResidentへ実作業を依頼して専用クライアントなしで監督する仕組みはM4で進める。

以上をM2 Stableの受入完了記録とする。
