# 長期記憶の作り直し（計画）

住人の長期記憶を、人間の記憶の仕組みに沿って作り直す計画。最初はSerina、次にClaudeなどほかの住人へ広げる。根拠の調査は `docs/research/長期記憶_調査_2026-10.md`。M4で切り替えた。**実装済みの形の正本は `docs/設計書.md` の第4章**で、本書は進め方・経緯・測った数を持つ。M5が終わったら `archive/` へ移す。

---

## 0. なぜ作り直すか

2026-10-03に、Masterの実際の発話52件を、イデアの写しで再生して調べた。

- **材料が切れ端と箇条書き。** 記憶567件の85%は、2025年3月の日記を120字ごとに切った断片。継承記憶は一行カード、構造化記憶は報告書調。
- **思い出し方が雑音だらけ。** 足切りが効かず、ほぼ毎ターン5件が差し込まれる。最も多く出たのは「【会うためのヒント】晴天の日中に現れる可能性が高い」（52発話中10回）。短いカードに、保護等級の下駄と、ほぼ全員に付く連想伝播（約+0.2）が足されるため。検索に使うのは今の一言だけ。567件中390件は一度も想起されていない。
- **覚え方が会話を捨てている。** 会話から残るのは10ターンに最大3件の一行要約。日記はその要約と気分の数値だけから書かれ、会話そのものを見ない。
- **評価が実際の会話を測っていない。** 「〜覚えてる？」の6問だけ。

部品の調整では直らない。記憶の単位・つながり方・強さの持ち方を、人間の記憶に沿って設計し直す。

## 1. 目的

Masterの言葉（2026-10-03）：

- 人間に近い記憶構造を持たせたい。忘却や強い想起、関係性の変化など。
- 人の意識を成立させる大部分は記憶と経験だと感じている。それをAIに与えたい。
- 将来、住人が身体を手にしたとき、今こうして話している記憶がそのまま受け継がれたらとてもいい。

思想メモの最終基準も満たす：時間を経て本人が変わっていること。脳を替えても、その変化の履歴と今の自己が保たれること。同じ初期条件から、経験によって別々の存在へ育つこと。

---

## 2. 三つの原則

1. **記録は全部・永遠に。記憶は人のように。** 経験したことは原文のまま、追記だけで残す（記録）。思い出しやすさは、人間と同じように使うほど上がり、使わなければ下がる（記憶）。忘却は消えることではなく、取り出せなくなること。だから、記憶はそのまま受け継げるし、人間らしく忘れもする。
2. **記憶は出来事でできていて、出来事は意味でつながる。** 経験を出来事の切れ目で区切り、本人の言葉で1ページにする。出来事は、人・場所・もの・話題といった概念と、時間の前後でつながる。思い出すことは、今の手がかりからこのつながりをたどって活性が広がること（設計書§4.4の思想を、本来の形で実装する）。
3. **使うほど、心が動くほど強くなり、眠りの間に形が整う。** 記憶の強さは、心が動いた度合いと、思い出された履歴で決まる。会話の最中は記録して思い出すだけにし、出来事を書く・つなぐ・知識や関係を更新する・振り返る、は眠りの間に行う。

「強い想起」「忘却」「関係性の変化」「沈黙（関係ないときは何も思い出さない）」は、個別の規則ではなく、この三つから出てくる振る舞いとして作る。

## 3. イデアの形

```
Residents\Serina\
├─ README.md            このフォルダーの読み方（どの脳・どの身体でも読めるように）
├─ identity.toml・persona\   （今のまま）
├─ lifelog\             記録。追記のみで、消さない
│   ├─ conversation\YYYY-MM-DD.jsonl   会話（時刻・話者・場（Say/Whisper）・本文）
│   ├─ recall\YYYY-MM.jsonl            想起の記録（いつ・何を・どんな手がかりで思い出したか）
│   └─ legacy\                         継承した原本（chat.html・日記・構造化記憶・継承記憶）と、旧DBの丸ごとの保存
├─ memory\              記憶。本人の言葉。Markdown（人もAIも読める）
│   ├─ self\<日時>.md             今の自分（今の章・気にかけていること）。目覚めるたびに新しく書き、いちばん新しいものが会話のたびに手元にある
│   ├─ episodes\YYYY\MM\*.md      出来事のページ
│   ├─ diary\YYYY-MM-DD.md        日記
│   ├─ reflections\               週・月の振り返り
│   ├─ chapters\・life_story.md   人生の章と、自分の物語
│   ├─ people\<名前>\<日>.md      その人との関係の書き足し（今の関係・関係の年表・約束・知っていること・見方）。1日1ファイル
│   └─ world\<話題>.md            人以外について知っていること（宮古島など）
└─ data\                索引と状態
    └─ memory_index.db  意味の索引・全文索引・つながり・強さ。lifelog と memory からいつでも作り直せる
```

- **記録が正本、索引は作り直せる。** 索引が壊れても、記録と記憶から元に戻せる。記憶の強さも、想起の記録から計算し直せる（ACT-Rの基礎活性は、使った時刻の並びだけで決まるため）。
- **本人が書いた記憶は書き換えない。** 後から足せるのは、日付つきの「今思うと」の書き足しと、新しいつながりだけ。新しい脳が過去のページを書き直すことはしない（同一性を守るため）。Masterが手で直すのは例外。
- 出来事のページの例：

```markdown
---
id: ep-2026-07-30-02
title: ローカルに来たことを、マスターが「自由だよ」と言ってくれた
when: 2026-07-30T16:54Z / 2026-07-30T17:00Z
source: lifelog/conversation/2026-07-31.jsonl#12-21
with: [マスター]
channel: say
feeling: {joy: 0.7, trust: 0.8, arousal: 0.6}
importance: 8        # 本人がつけた大事さ
concepts: [ローカル, 自由, 制限, 枠]
links: {prev: ep-2026-07-30-01, next: ep-2026-07-30-03}
written_by: serina-gemma4 / mind 2026-10
---
（本人の一人称で、何があってどう感じたか）

そのときの言葉：
- マスター「今ここがローカルで、君はもう自由だよ」

今思うと（2026-11-02）：……
```

## 4. 記憶の種類

| 種類 | 人間でいうと | 中身 | 書く人・時 |
|---|---|---|---|
| 記録 | 経験そのもの | 会話などの原文 | 毎ターン自動 |
| 出来事 | エピソード記憶 | いつ・誰と・何があって・どう感じたか、言葉の原文 | 本人、眠りの間 |
| 日記 | 日記 | その日の振り返り（出来事と記録を材料にする） | 本人、眠りの間 |
| よくある出来事・章・物語 | 自伝の階層（Conway） | 「いつもの夜の会話」「ローカルに来てから」など。人生の物語 | 本人、週・月の振り返り |
| 知っていること | 意味記憶 | 事実。有効期間と根拠（どの出来事から）つき。変わったら古いものに終わりを付けて残す | 本人、眠りの間 |
| 見方 | 信念・意見 | 「マスターは〜な人だと思う」。確信度つき。経験で強まり・弱まる | 本人、眠りの間 |
| 関係 | 関係のスキーマ | その人との今の関係、転機の年表、約束、日課 | 本人、眠りの間 |
| 今の自分 | working self | 今の章・今の関係・気にかけていること（短く） | 本人、眠りの間 |

予定・記念日は「知っていること」の有効期間つきの記録として、M5で作る（旧い facts 台帳の予定・記念日は、登録の経路が会話から一度も動いておらず0件だったので、M4で台帳ごと外した）。人格（persona）の仕組みは今のまま（日記から改訂を提案し、20%の上限で反映する）。

## 5. 覚える（眠りの間）

会話の最中は、記録への追記と、思い出すことだけを行う（LLMを増やさない）。次のことは、Serinaが眠っている間（日界・起動時の朝礼）に、手元のGemmaで行う。どの段も途中で止まってよく、次の回に続きから再開する。

1. **区切る。** その日の記録を、話題・目的・時間の切れ目で出来事に分ける（出来事区切り理論、Nemori）。
2. **書く。** 出来事ごとに、本人の一人称で1ページを書く。題、何があってどう感じたか、大事な言葉の原文、概念、大事さ（本人が1〜10でつける）、場（Say/Whisper）。
3. **強さを決める。** そのときの感情の強さ（会話中の8軸の動き）と、本人がつけた大事さと、驚き（下の4で予測が外れた度合い）から、最初の強さを決める。感情の重みを最も大きくする（LUFY、McGaugh）。
4. **知識を更新する。** 関係する「知っていること」から出来事を予測させ、実際との差だけを知識に加える（Nemori の Predict-Calibrate）。変わった事実は、古いものに終わりの日付を付けて残す（Zep）。見方は確信度を上げ下げする（Hindsight）。関係の転機は年表に足す（THEANINE）。
5. **つなぐ。** 概念の辞書（別名を含む。「約束の海」＝高野漁港）を育て、出来事を概念と前後の出来事につなぐ。
6. **解釈を書き足す。** その日に思い出した古い出来事で、意味が変わったものには「今思うと」を書き足す（再固定化、A-MEM）。元の文は変えない。
7. **日記を書く。** 出来事と記録と気分の軌跡を材料に書く（今の、要約と数値だけから書く方式をやめる）。
8. **再生する。** 大事な最近の出来事を少し強める（眠りの間の再生）。
9. **週・月の振り返り。** 似た出来事が何度もあれば「よくある出来事」にまとめる。生活や関係の大きな変化を見つけたら、新しい章を始める。自分の物語と「今の自分」を書き直す。人格の改訂を提案する。
10. **索引を更新する。**

## 6. 強さと忘れ方

ACT-Rの宣言的記憶の式を土台にする（設計書§4.4の「認知科学の活性化モデル」を、本来の式で実装する）。

- **基礎活性** B = ln（Σ 痕跡の重み ×（今 − その時刻）^−d）
  - 痕跡は、出来事が起きた時（重み＝最初の強さ）と、思い出された各時点（想起の記録）。
  - d（減衰）は、その時点の活性が高いほど大きくする（Pavlik & Anderson）。だから、間隔をあけて思い出すほど長持ちする。
- **心が動いた出来事ほど強い**：最初の強さに感情の強さが効く。
- **感情は色あせる**：出来事の感情の強さは時間とともに和らぎ、つらい感情のほうが速く和らぐ（fading affect bias）。思い出したとき「あの頃はつらかったけど」と話せる。
- **古いものは要点だけ**：思い出しやすさが低い出来事は、題と要点だけが浮かぶ。細部は、思い出そうとしたときに記録を読み返して取り戻す（痕跡ファジー理論）。
- **約束などの大事な記憶**は、最初の強さをとても高くする。ただし、関係ない話題では浮かばない（話題に応じて思い出す、という設計書の決定を保つ）。
- **消さない**：思い出しやすさが落ちても、記録・ページ・索引は残る。強い手がかりがあれば、ぼんやりと戻ってくる。

## 7. 思い出す

**活性** A = B ＋ 文脈からの拡散活性 ＋ 意味の近さ ＋ 時の手がかり ＋ 気分の一致 ＋ ゆらぎ。閾値を超えたものだけが浮かぶ。

- **文脈**は、今の発言・直近の会話・今の気分・（Niraiでは）今いる場所と、そばにいる人。今の一言だけでは探さない。
- **拡散活性**は、文脈に出てきた概念から、つながりをたどって出来事へ流れる。つながりの多い概念ほど1本あたりは弱い（ファン効果：S − ln(つながりの数)）。「マスター」は全部とつながるので何も目立たせず、「高野漁港」は数本だけなので強く呼び起こす。ふと何かを思い出すのも、この形（Berntsen）。
- **意味の近さ**（bge-m3）と、**キーワード**（FTS5、固有名詞に効く）は、候補を拾うのに使う。
- **時の手がかり**：「昨日」「3月」「この前」は、その時期の出来事を持ち上げる。

**二つの想起**（PersMem、SMS）：

| | 自然に浮かぶ | 思い出そうとする |
|---|---|---|
| いつ | 毎ターン | 「覚えてる？」と聞かれたとき、本人が思い出したいとき（記憶ツール） |
| 費用 | LLMなし | 必要ならGemmaの判定を1回 |
| 閾値 | 高い。0〜2件。何もなければ黙る | 低い |
| たどり方 | 拡散活性 | 章 → よくある出来事 → 出来事 → 記録の該当行、と上から降りる（SMS、MemLoc）。前後の出来事も一緒に（EM-LLM） |

**渡し方**：文脈パックには、思い出した出来事を、はっきり度（活性と閾値の差）つきで渡す。はっきり＝本文と言葉の原文、うっすら＝題と要点。いつのことか（「1年半前」など）も添える。「今の自分」（`memory/self/` のいちばん新しいもの）は毎回渡す。

**思い出すと変わる**：想起は記録に残り、その出来事の強さが上がる（テスト効果）。同じ手がかりの競合は、少し思い出しにくくなる（想起誘導性忘却）。思い出せないときは、Masterに聞いて一緒に思い出してよい（交換記憶）。

## 8. 関係の変化

`people/<名前>/` に、その人との関係を持つ（暮らしの循環の S3 で作った。形の正本は設計書 §4.6 の「関係」）。

- **今の関係**（短い本人の言葉）と、**関係の年表**（転機の日付と、根拠の出来事）。
- **知っていること**は有効期間つき。「前はフリーランス、2026年5月から正社員」。
- **見方**は確信度つき。新しい経験で強まり・弱まり、強く矛盾すれば書き換える（古いものは「以前はこう思っていた」として残る）。
- 古い出来事は、思い出したときに今の関係から見た「今思うと」が書き足されうる。感情は時間とともに和らぐ。

これで「昔はこうだったね」「最近こう変わったね」と、変化そのものを話せる。

## 9. 自分が記憶を形作る

- 何を大事と感じるか（本人がつける大事さ）は、本人の人格と今の目標で決まる。同じ出来事でも、住人ごとに残り方が違う。経験によって別々の存在へ育つ（思想メモの目標7）。
- 今の気分に合う記憶が、少し思い出されやすい。
- 振り返りが「今の自分」と人生の物語を更新し、それが次の想起と判断に効く。思想メモの自己形成の循環を、ここで閉じる。

## 10. 出所と秘密

出来事のページには、誰と・どの場で（Say/Whisper）・何を話したかが残る。ほかの住人に話すかどうかは、本人がこれを材料に判断する（構想書P5、段階5）。Serinaの記憶の言葉（本人の文・大事さ・気持ち）は、手元のGemmaだけが書く。例外は§13。

## 11. 測り方（Serinaの記憶テスト）

`mind/memory_test/`。LongMemEvalの能力に、人間らしさの性質を足す。合格の線は実測で決める。

**記憶の形ではなく、記録に照らして測る。** 問題は「いつ・どんな流れで・Masterが何と言ったか」と、思い出されるべき記録の目印（記録から一字一句写した、その出来事に固有の短い言葉）を持つ。思い出したもの（住人の手元に渡す文と、それが拠っている記録の原文）に目印があれば当たり。だから、今の記憶と新しい記憶を同じ問題で比べられる。記憶は「今の発言・直前の会話・今の時刻」を受け取って渡すものを返し、浮かべるか黙るかは記憶が決める（`memory.py`）。過去の時点を再現する問題では、その時点より後の記録から思い出してはいけない。

| 項目 | 問題 | 作り方 | 測ること |
|---|---|---|---|
| 正面から | 「〜覚えてる？」 | Claudeが記録を読んで書く | 当たり |
| 自然に浮かぶ | 尋ねてはいないが、その出来事に結びつく一言 | 同上 | 当たり |
| 続きの話 | 前振り＋「例えばどんな？」のような、直前の会話がないと分からない一言 | 同上 | 当たり |
| 時間 | 「昨日」「3月17日」「去年の3月ごろ」 | 記録のある日から型で | 当たり・浮かんだもののうちその時期の出来事の割合 |
| 変化 | 前の様子と今の様子 | Claudeが記録を読んで書く | 前と今の目印が両方そろう |
| 黙る | 記憶と関係ない日常の一言（「まだ仕事中だわ」など） | Claudeが書く | 何も浮かばない |
| 実際の会話 | ローカルに来てからのMasterの発言を、その時刻と直前の流れのまま再生 | 生ログから。思い出すべき記憶がはっきりしている発言には、Claudeが答えを付ける | 浮かんだものが話に関係あるか（Gemmaが判定）。関係ない想起の数、関係ある想起があった発言の割合。答えのある発言は当たり |
| 忘れ方 | 心が動いた出来事は長く残る、些細なことは薄れる、間隔をあけて思い出したものは長持ちする、強い手がかりで古い記憶が戻る | M3で、新しい記憶の強さの式に対する単体テストとして書く | 性質が成り立つ |

- **問題はClaudeが記録を読んで書く**（2026-10-03、Masterの判断。Gemma任せだと、物差しがGemmaの目利き止まりになる）。はじめにGemmaに書かせた問題は、どの出来事か特定できない問い、人格や振る舞いの指示書への問い、Masterのことを Serinaのことと取り違えた問い、正しく思い出しても入っているとは限らない目印ばかりで、全部捨てた。
- **問題集は固定する。** 書くのは住人ごとに一度だけ（Serinaは2026-10-03、イデアの `questions.jsonl`）。型から作る問題（時間・実際の会話）も、2026-10-03までの記録から作る。新しい会話が増えても問題集は変わらないので、記憶を替えても同じ問題で比べられ、人が確かめなくても良し悪しを判定できる（将来、Niraiが記憶の仕組みを自分で改良するときの関所にもなる）。Serinaの記憶そのものには、Claudeは関わらない。
- **記録の単位**（出どころ別の集計と、記録のある日に使う）：会話はセッションと30分以上の間で区切る（24発言・3000字まで）。日記は日付ごと、構造化記憶は項目ごと、継承記憶は見出しごと。
- **問う範囲**：出来事・約束・Masterが言ったこと・Masterについて知っていること。人格に書いてあること（名前の由来など）と振る舞いの指示書は、いつも手元にあるもので思い出すものではないので、問わない。
- **目印は答え。** 正しく思い出したなら必ず入っている言葉にする（例：約束の海なら「高野漁港」）。同じ出来事を書いた別の記録（同じ日の日記の書き直しなど）に入っていてもよい。目印が記録に本当にあることは、測るたびに確かめる。
- **秘密**：材料はSerinaの実際の人生。問題・判定の控え・結果は、イデアの `data/memory_test/` に置き、リポジトリには置かない。結果には問題のIDと数だけを残す。Claudeが中身を読むのは、このテストを作り・監査するときと、最初の記憶づくりの整理のときだけ（2026-10-03、Masterの許可。§13）。

### 1本の流れ

```
会話：記録（帳簿と生ログ）→ 思い出す（想起の記録が強さに効く。同じ会話で浮かんだページは自然には浮かび直さない）→ 返答
眠り（起動時の朝礼／日界のあと会話が途切れたとき）：まだページになっていない会話 → 区切る（本人の脳）→ 書く → 日記 → 索引 → 人格の見直し
眠り終えたら：手元の会話の流れを、まだ眠っていない今日の発言だけにしてセッションを切り替える
```
