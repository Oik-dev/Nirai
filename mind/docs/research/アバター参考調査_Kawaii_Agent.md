# アバター参考調査 — Kawaii_Agent

出典: https://github.com/miu-chang/Kawaii_Agent（2026-07-26確認、README・ファイル構成・主要ロジックの要約のみを参照。コード本体は未転記）

## 1. 感情→表情マッピング

感情の種類ごとに、顔のパーツをどう動かすかを直接対応させる表を持つ。

| 感情 | 表情の作り方 |
|---|---|
| happy | `happy`プリセット、または口を「い」の形に強さ0.6 |
| sad | `sad`プリセット、または口を「う」の形に強さ0.4 |
| angry | `angry`プリセットをそのまま適用 |
| surprised | `surprised`プリセット＋口を「あ」の形に強さ0.8 |
| thinking | `relaxed`表情 |
| neutral | 全表情をクリア |

感情の強さは `min(強さ × 1.3, 1.0)` で1.3倍に誇張してからブレンドシェイプに反映する（弱いままだと表情が地味に見えるための補正）。毎フレーム（`useFrame`内）で表情パラメータを再設定し続ける方式。

## 2. 母音ベースの口パク

発話中かどうか（`isSpeaking`）だけを見て、口の形を一定間隔（0.15秒ごと）で切り替える。

- VRM: `あ`/`お`の2形状を交互に切り替えるだけの簡易版
- MMD: メッシュ内の頂点モーフから「あいうえお」＋英語表記のモーフを探し出し、発話中はそのモーフ番号を使って口を動かす（実際の発話内容とは同期していない、機械的な母音切り替え）

音声解析（実際の音の周波数など）は使わず、「喋っている/いない」の二値だけで駆動している点がポイント。

## 3. 待機モーション＋感情連動ジェスチャーの切替

常時流れる待機モーションと、感情が動いたときだけ割り込むジェスチャーの二層構成。

- **待機モーション**（`IdleMotion`）: 呼吸（胸・脊椎の微細回転）、まばたき（2〜5秒のランダム間隔）、頭の緩やかな揺れ、腕の自然な揺動を常時再生
- **ジェスチャー**（`GestureManager`）: 感情が変化した瞬間に対応するジェスチャー（happy→喜びの仕草、など）を1回再生。再生中は待機モーションを止め、終わったら待機モーションに復帰する優先度制御
- マウス追従（`MouseFollower`）: マウス座標をボーンの回転量に変換し、視線がカーソルを追う演出

「常時ランダムに小さく動く土台」の上に「感情が動いた瞬間だけ明示的な仕草を上乗せする」という二層構造が、キャラクターの生きてる感を作っている要点。
