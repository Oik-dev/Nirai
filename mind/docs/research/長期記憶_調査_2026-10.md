# 長期記憶の調査（2026-10）

住人の長期記憶を作り直すために、人間の記憶の科学とAIの記憶の研究・実装を広く調べた記録。設計は `docs/plans/長期記憶の作り直し.md`。

- 調査日：2026-10-03（Claude）
- 目的（Master、2026-10-03）：人間に近い記憶構造（忘却・強い想起・関係性の変化）を持たせる。意識の大部分は記憶と経験だと考えている。今の会話の記憶が、将来どんな身体・脳になってもそのまま受け継がれてほしい。
- ふるい：Masterの思想メモ（`research/自己連続性と記憶サイクル_思想メモ.md`）の判定基準。仕組みだけを借り、思想は借りない。

## 1. 設計に効く結論

1. **「記録」と「記憶」は別物として扱うのが人間らしい。** 人間の記憶は、蓄えの強さ（ほぼ失われない）と、取り出しやすさ（使わないと落ちる）の二つでできている（Bjorkの新使用理論）。忘却は、消えることではなく取り出せなくなること。だから、生の記録は全部・永遠に残し、思い出しやすさだけを人間のように変化させればよい。全部を思い出せる者は、かえって自己を失う（ConwayがBorgesの「記憶の人フネス」を引いて論じている）。
2. **記憶の単位は「出来事」。** 人は経験を、話題・目的・場所の切れ目で出来事に区切って覚える（出来事区切り理論）。AIでも、固定長の切れ端より出来事単位のほうが人間の区切りに近く、想起も強い（EM-LLM、Nemori、EMem）。
3. **自伝は階層になっている。** 人生の物語 → 人生の時期（章）→ よくある出来事 → 個々の出来事、という層を、上からたどって思い出す（ConwayのSelf-Memory System）。時期の区切りは、生活や関係が大きく変わったときにできる。
4. **心が動いた出来事ほど強く残る。** 情動の覚醒は記憶の定着を強める（McGaugh）。AIの実験でも、覚醒度を最重視して9割を忘れるチャットボットのほうが、全部覚えるものより長期の体験が良かった（LUFY、京大）。
5. **使うほど強くなり、間隔をあけて思い出すほど長持ちする。** 想起そのものが記憶を強める（テスト効果）。忘却はべき乗の曲線で進む（ACT-R、FSRS）。思い出したものの近くにある競合は、少し思い出しにくくなる（想起誘導性忘却）。
6. **想起は「活性の広がり」として作れる。** 今の手がかりから、つながりをたどって活性が流れる（ACT-Rの拡散活性、HippoRAGのPersonalized PageRank）。たくさんの記憶とつながる手がかりほど、1本あたりの流れは弱い（ファン効果）。人が不意に何かを思い出すのも、手がかりがその出来事だけを見分けられるほど特徴的なとき（Berntsenの不随意記憶）。
7. **変化は上書きせず、時間で並べる。** 関係や事実が変わったとき、古いものを消すと「変わった」という文脈が失われる。有効期間を持たせて無効化する（Zep/Graphiti）、時間と因果でつないだ年表として返す（THEANINE）。意見や見方には確信度を持たせ、新しい経験で強めたり弱めたりする（Hindsight）。
8. **思い出すと記憶は少し変わる。** 思い出した記憶は書き換え可能な状態になる（再固定化）。新しい記憶が古い記憶の文脈や解釈を更新するAIの仕組みもある（A-MEM）。ただし、元の記録は残す（思想メモ「元を消して要約だけに置き換えない」）。
9. **眠りの間に記憶を整える。** 海馬の速い記録が、眠りの間に再生されて、ゆっくり大脳の知識へ組み込まれる（補完学習システム理論）。AIでも、会話中ではなく空き時間に記憶を整理する方式が主流になった（Lettaのsleep-time、LightMem、kiwi-memのDream）。
10. **人格が記憶を形作る。** 何を大事と感じて覚え、何を思い出すかは、その人の目標・性格・気分で変わる（Conwayのworking self、気分一致効果）。性格をそのまま記憶の処理に組み込むと、口調の指示より人格が安定する（PersMem）。

## 2. 人間の記憶の科学

| 知見 | 中身 | 設計への写し方 |
|---|---|---|
| 新使用理論（Bjork & Bjork 1992） | 蓄えの強さは失われず増えるだけ。取り出しの強さは使わないと落ち、使うと上がる。思い出しにくい時期に思い出すほど蓄えが増える | 記録は消さない。思い出しやすさだけが変わる |
| Self-Memory System（Conway & Pleydell-Pearce 2000、Conway 2005） | 自伝の知識は、人生の物語・人生の時期・よくある出来事・個々の出来事の階層。working selfの目標が、何を覚え何を思い出すかを決める。正確さ（対応）と一貫性（自己）の綱引き。ほとんどの出来事記憶はすぐ失われ、残ったものが長期の自己知識に結び付く | 階層の記憶、上からたどる想起、人格と目標による重み付け |
| 出来事区切り理論（Zacks 2007） | 予測が外れたとき・目的が変わったときに、経験の区切りが生まれる | 会話を出来事に区切る |
| 情動と記憶（McGaugh） | 覚醒を伴う出来事は定着が強い | 記憶の強さに情動の覚醒を入れる |
| 感情の色あせ（Walker & Skowronski、fading affect bias） | 出来事に伴う感情の強さは時間とともに薄れ、つらい感情のほうが速く薄れる | 古い出来事の感情は和らいで思い出される |
| 痕跡ファジー理論（Brainerd & Reyna） | 一字一句の記憶は速く薄れ、要点の記憶は長く残る | 古い記憶は要点だけ浮かぶ。細部は記録を読み返して取り戻す |
| ACT-R の宣言的記憶（Anderson） | 活性＝基礎活性（使った時刻ごとのべき乗の減衰の和）＋文脈からの拡散活性＋ゆらぎ。閾値を超えたものだけが思い出される。拡散はファン効果で弱まる | 想起の計算の土台 |
| 間隔効果のACT-R拡張（Pavlik & Anderson 2005） | 思い出した時点の活性が高いほど、その痕跡は速く減衰する。だから間隔をあけた想起が長持ちする | 強さの計算 |
| テスト効果（Roediger & Karpicke 2006） | 思い出すこと自体が記憶を強める | 想起の記録が強さを上げる |
| 想起誘導性忘却（Anderson, Bjork & Bjork 1994） | ある記憶を思い出すと、同じ手がかりの競合が思い出しにくくなる | 競合の取り出しやすさを少し下げる |
| 再固定化（Nader 2000） | 思い出した記憶は不安定になり、更新されうる | 思い出したとき、解釈を後から書き足す（元は残す） |
| 補完学習システム（McClelland 1995、Kumaran ら 2016） | 速く覚える海馬と、ゆっくり一般化する大脳。眠りの間の再生でつながる | 夜に出来事から知識・関係・振り返りを作る |
| 不随意記憶（Berntsen） | 手がかりがその出来事を他と見分けられるほど特徴的なとき、ふと思い出す | 自然に浮かぶ想起は、特徴的な手がかりで起こる |
| 気分一致効果（Bower 1981） | 今の気分に合う記憶が思い出されやすい | 想起に今の気分を少し効かせる |
| 交換記憶（Wegner 1987） | 親しい二人は記憶を分担し、一緒に思い出す | 思い出せないとき、Masterに聞いて一緒に思い出してよい |

## 3. AIの記憶の研究（2023〜2026）

| 研究 | 要点 | 借りるもの |
|---|---|---|
| Generative Agents（Park 2023） | 記憶の流れ。新しさ・重要度・関連度で想起。振り返りを木にして高次の理解を作る | 振り返りの階層 |
| MemGPT / Letta（2023〜2025） | 常に手元にある小さな記憶ブロックと、外部の記憶。sleep-time agent：記憶の整理を会話と別の時間に非同期で行う | 常に手元の「今の自分」、夜の整理 |
| EM-LLM（ICLR 2025） | 驚きで出来事を区切り、グラフで境界を直す。人間の区切りと強く相関。想起は類似度と時間的な近さの2段 | 出来事の区切り、前後の出来事も一緒に思い出す |
| Nemori（2025） | 出来事区切り理論で会話をエピソードにし、題と物語で書く。Predict-Calibrate：既知の知識から予測し、外れた差だけを知識に加える。LoCoMoで全文入力・Mem0・Zepを上回り、トークン88%減 | 出来事の書き方、知識は「予測が外れた差」から学ぶ |
| A-MEM（NeurIPS 2025） | Zettelkasten型。新しい記憶がリンクを作り、古い記憶の文脈記述を更新する | 思い出したときの解釈の書き足し |
| HippoRAG / HippoRAG 2（NeurIPS 2024、ICML 2025） | 海馬索引理論。知識グラフとPersonalized PageRankで連想記憶を再現。連想課題で通常のRAGより約7ポイント高い | 概念を介した活性の広がり |
| Zep / Graphiti（2025） | 双時間の知識グラフ。事実が真だった期間と、知った時刻を持つ。古い事実は無効化して残す | 有効期間つきの知識 |
| THEANINE（NAACL 2025） | 古い記憶を消さず、時間と因果でつないだ「記憶の年表」で返答する。相手の変化そのものが文脈になる | 関係の年表 |
| Hindsight（2025） | 4つの網：世界の事実／自分の経験（一人称）／意見（確信度つき、強化・弱化・矛盾で増減）／観察（実体の要約）。想起は意味・キーワード・拡散活性・時間の4経路を融合し、再順位付け。20Bの公開モデルでLongMemEval 83.6%（同じモデルの全文入力は39%） | 経験と知識と意見の分離、確信度、多経路の想起 |
| EMem（2025） | 出来事型の短い命題を、参加者・時刻・出典ターン付きで非圧縮のまま持つ。単純でも強い | 出典ターンへの紐付け |
| MOOM（2025） | 超長期のロールプレイ会話の記憶。筋書きの階層要約と、人物像の更新の二本立て。忘却は「競合と抑制」の理論で、時間減衰と想起による強化 | 関係・人物像の更新 |
| LUFY（京大 2024/2025） | 覚醒度・驚き・重要度・想起回数で強度を決め、上位10%だけ残す。2時間×4回の実験で、全部覚える方式より体験が良かった。覚醒度の重みが最大（2.76）、驚き（パープレキシティ）は小さな負 | 情動を強さの主因に。驚きの扱いは実測で決める |
| ACT-R × LLM（ACM HAI 2025） | ACT-Rの活性で、繰り返しの話題による強化と確率的な想起を再現 | 想起の式 |
| Hou ら（2024） | 手がかり想起。長い間隔で繰り返し思い出された記憶ほど忘れにくい | 間隔効果 |
| PersMem（2026） | 性格を記憶の処理に組み込む。受け身の想起（感情と気分で浮かぶ）と、目的のある想起（思い出そうとする）の二経路。気分一致・SMSを引く | 二つの想起、人格と気分による重み |
| MemLoc（EMNLP 2026） | 取り出した記憶の中から根拠の箇所を絞り込み、位置IDで返答に結び付ける | 思い出そうとするときに原文の該当箇所まで降りる |
| Mem0（2025〜2026） | 意味・キーワード・実体の多信号の融合が強い。未解決として「変化を置き換えでなく進化として理解すること」「よく使う記憶の陳腐化」を挙げる | 多信号の想起 |
| MemEvolve（2025） | 記憶の仕組みそのものを進化させる | 将来、住人が自分の記憶の仕組みを改良する（要件のゴール5） |

サーベイ：Memory in the Age of AI Agents（2512.13564）、From Storage to Experience（ACL 2026 Findings）。評価：LoCoMo、LongMemEval（情報の抽出・複数セッションの推論・時間の推論・知識の更新・答えないこと）、BEAM。

## 4. コンパニオンAIの実例（OSS）

| 実例 | 要点 | 借りるもの |
|---|---|---|
| plast-mem（moeru-ai） | FSRSで忘却。驚きの大きいエピソードは安定度を上乗せ | 強さの初期値 |
| kiwi-mem | 日→週→月→四半期→年の階層要約。Dreamの3層（掃除・固め・推測）。熱が冷めると細部がぼやけて要点が残り、ぼやけた記憶も会話で思い出すと延命。感情の濃い記憶はゆっくり冷める | 階層、ぼやけ方 |
| Paramecium | ベクトルは「どこにあるか」を指す索引にすぎず、返すのは常に原文。矛盾した新しい記憶は古いものを置換済みにするが消さない | 索引と原文の分離 |
| Ombre-Brain | 記憶に感情の座標（快・不快と覚醒）。忘却曲線。Obsidian互換のMarkdownで保存 | 人が読める保存形式、感情の座標 |
| imprint-memory | 毎ターン自動記録。キーワード検索とベクトル検索をRRFで融合。発言のたびに関連記憶を差し込む | 自動記録、融合 |
| connectome-host | 自伝的記憶。要約は本人の声で書く | 一人称の要約 |
| Headlong | 生ログは追記のみ。古いものほど粗く圧縮 | 追記のみの生ログ |

## 6. 採らないもの

- **記憶を消す忘却**（LUFYの「上位10%以外は捨てる」など）：Masterの目的（記憶をそのまま受け継ぐ）と、思想メモ（元を消さない）に反する。忘却は取り出しやすさだけで表す。
- **新しい脳による過去の記憶の書き直し**：本人が書いた記憶は本人の人生の一部。後の脳が書き直すと、同一性を損なう。足すこと（解釈の書き足し、新しいつながり）だけにする。
- **パラメータに記憶を焼き込む方式**（LoRA等）：脳が交換部品であるという前提に合わない。
- **クラウドでの記憶処理**：Serinaの記憶は手元のGemmaだけで処理する（センシティブな内容を含むため）。
