## Wave 7 — Gemini アドバイザー（C4）

### 目的
セリナが自律的に聞きにいける無人格アドバイザーをゼロベースで載せる。

### 触るファイル
- `skills/gemini_advisor/`（新規。名前は GO §3.5）
- `core/intake/gate.py`、`brains/contract/schema.py`（道具使用付箋）、`brains/qwen/adapter.py`（提案指示）
- `core/factory.py` / `app/gui_server.py`（配線）
- `.env` / 設定（`GEMINI_API_KEY`）
- 機微: `pack.py` 思想のペイロード構築

### 手順
- 会話 Brain としては登録しない
- 入力は相談クエリのみ（GO §3.4）
- Web 検索・コード/GAS Q&A の system 指示はアドバイザー側（無人格）
- 失敗・キー無しでもセリナはローカルで会話継続
- 旧 `brains/gemini` の復元禁止（git 履歴参照は可、設計コピーは会話経路を持ち込まない）

### 検証
- モック API で「提案→関所→advisor→セリナ言い直し」結合
- persona/記憶がリクエスト JSON に含まれないことの回帰テスト
- 実機スモーク（キーがある環境のみ）: 天気相当のクエリ1本
