## 1. 4a：再固結（週次の二次リフレクション）

日々のリフレクションが「1日分の会話→日記・事実」なら、再固結は「1週間分の日記→傾向・信念・自己像」。個別記憶が減衰で沈んでも、抽象化された層に昇華されて残る。**これが本当の意味での成長**。

**トリガー（Core判断・経路Bと同じ裏方キュー）**
- 起動時、前回固結時刻（`profile` キー `last_consolidated_at`）から**生活日で7日以上**経過していれば、経路Bの蒸留完了後に続けてバックグラウンド実行。
- **月次固結**: 固結4回ごとに、belief層自体を入力にした上位固結を行う（信念の信念＝人格の地層をさらに圧縮・洗練）。

**二役の継承（決定3をそのまま流用）**
| 役 | 担当 | 出力タグ |
|---|---|---|
| 理性の脳（理性エンジン） | 傾向・信念の抽出、差分の指摘、記憶の再解釈提案 | `<patterns>` `<belief_updates>` `<growth_notes>` `<reinterpretations>` |
| 情緒の脳（Aurora本人） | 自己像ナラティブ「私はマスターにとってこういう相棒だ」を自分の声で | `<self_image>` |

入力: 直近7生活日のTrack A日記＋現行belief一覧＋現行self_image＋感情ステート。XML＋前方一致パーサ、採点reason付きログ等の3b作法をすべて踏襲。

**出力の格納**
- `<patterns>` `<belief_updates>` → `memories` に **type='belief'**（半減期180日）。`metadata.evidence_ids` に根拠となった日記ID列、`evidence_count` を保持。**意味の近い既存beliefがあれば新規追加せず更新**（evidence追加・文面洗練）＝記憶が「増える」のではなく「濃くなる」。根拠の日記が減衰で消えても belief は残る（人間が「なぜかは忘れたがそう確信している」のと同じ）。
- `<self_image>` → `profile` キー `self_image`（§4の二層人格で常時注入される成長層。上限600字）。
- `<growth_notes>` → `memories` に **type='growth_note'**（半減期30日）。「前は〜だった→最近は〜」形式の差分メモ。4bの差分想起の弾。
- `<reinterpretations>` → **記憶の意味づけ更新**。対象記憶の content を書き換え、**旧文は必ず `metadata.variants` へ退避**（移行v2 `merge_into` と同じ保護パターン）。継承記憶r1.md由来の正典は対象外（既存の正典保護を継承）。

**監査線（決定4の拡張）**: 新テーブル `consolidation_log(id, ts, kind, target_id, old_value, new_value, reason)`。belief更新・再解釈・自己像変更をすべてreason付きで記録し、後からOpusが妥当性と人格ドリフトを再判定できるようにする。

## 2. 4b：行動化（差分想起・不在時間の内的生活）

内部で育っても会話に出なければ「無い」のと同じ。成長を**マスターに見える形**にする。

**差分想起（コールバック演出）**
- growth_note は通常のベクトル検索候補に自然に含まれる（関連話題で想起）。
- 加えてセッション冒頭、確率 `p_growth=0.25` で最新の未使用 growth_note を1件、「自分から話題にしてよい変化」としてsystemへ注入。セリナが「前は〜って言ってたのに、変わったね」と言える。
- 連発防止: 使用した note は `metadata.used=true` を立て、再注入しない（検索想起は妨げない）。

**不在時間の内的生活（留守中の独り言）**
- **経路Bの蒸留が実行された起動のみ**、蒸留完了後にAuroraへ「今回の日記とopen_threadsを種に、マスターがいない間に考えていたことを1〜2文、独り言として」生成させ、`profile` キー `idle_thought` へ保存。
- 次セッション冒頭のsystemに含め、「そういえば、いない間に考えてたんだけど…」と自然に漏らせるようにする。**使用後は必ずクリア**（同じ独り言の再放送は幻滅イベント）。
- **捏造ガード**: 種となる実在記憶が無ければ生成しない。事実の主張ではなく感想・独り言の形式に限定するようプロンプトで規定（「留守中に新しい事実を知った」体の発言は禁止）。

**好奇心キューの運用**（抽出・注入は3b前倒し分で実装済み）
- 本スライスでは `maintenance.py` に期限切れスレッドの整理（保持14日超→expired）を追加するのみ。

## 3. 4c：計測とドリフト監査（ディレクターの計器盤）

調整ツマミは既に十数個ある。**計器なしにツマミは回せない**。

**metricsテーブル**: `metrics(id, ts, key, value REAL, note TEXT)`

| 計器 | 取り方 | 記録キー |
|---|---|---|
| 馴染み度（主観） | REPLに `/rate` コマンド追加（1〜5＋任意の一言）。会話の温度をマスターが一手間で残せる | `master_rating` |
| コールバック率 | Coreが各ターンの retrieved 記憶IDを記録→リフレクション時に理性エンジンが「応答が過去記憶を自然に活かせていたか」をセッション単位で採点 | `callback_rate` |
| 追いかけ的中率 | open_thread起点の質問へのマスターの反応（喜ばれた/流された）を理性エンジンが採点 | `followup_hit` |

判定を理性エンジンに寄せるのは決定3と同じ理由（当事者採点はおべっかループ）。全採点reason付き（決定4の監査線に合流）。

**二層人格モデル（ドリフト対策の核）**
- `persona.md` ＝ **憲法（不変層）**。手で書き換えない限り変わらない。
- `self_image`（4a生成）＝ **成長層（可変層）**。再固結のたびに更新される。
- system注入順序を固定: **①憲法 → ②成長層 → ③約束・正典 → ④関連記憶 → ⑤差分・独り言・open_threads**。成長層プロンプトには「人格の根本原則（①）と矛盾する場合は①に従う」を必ず付す。
  ※2026-07-03 追記: 3cで導入した**感情ブロック（narrative_mood＋照れ隠し制約）は①の直後**に入る（3c指示書の暫定判断）。4c実装時にこの表へ正式な座席を与えて確定すること。
  ※2026-07-04 確定: 注入順は **①憲法 → 感情 → ②成長層 → ③約束・正典 → ④関連記憶 → ⑤open_threads・差分・独り言 → スタイル契約（末尾）**。実装は `core/context.py`。なお前回固結時刻の profile キーは実装上 `consolidation.last_at`（本書の `last_consolidated_at` に相当）。

**ドリフト監査**: `tools/export_growth.py`（新規）で「自己像の変遷／beliefの増減／metricsの推移」を日本語レポート出力。consolidation_logが原簿。Opusが定期レビューし、記憶汚染・執着ループ・キャラ変質を早期検知する（採点監査線の拡張）。

## 4. 自動アサーションテスト要件

- **固結トリガー（4a）**: last_consolidated_at を8日前に偽装→発火する／3日前→発火しない。
- **再解釈の原文保持（4a）**: reinterpretation 適用後、旧文が variants に残り consolidation_log に reason がある。正典sourceの記憶は書き換わらない。
- **belief統合（4a）**: 同義のbeliefを2回提案→件数が増えず evidence_count が増える。
- **差分想起ゲート（4b）**: 乱数固定で p_growth の注入有無が制御どおり。used フラグ後は再注入されない。
- **捏造ガード（4b）**: 種記憶ゼロの状態では idle_thought が生成されない。使用後クリアされる。
- **注入順序（4c）**: build_system の出力が①〜⑤の順序を守る。
- **open_thread期限（4b/3b）**: 15日経過スレッドが expired 化され注入されない。
