# Serina ドキュメント索引（INDEX）

最終更新: 2026-07-12（Phase 6 大掃除・ゼロベース仕上げ）

## 概要

本書とは、Serina の全ドキュメントの「どの資料のどの章に何が書いてあるか」を引くための索引である。

- 資料は3区分で管理する
  - **正典**: 実装・修正の根拠にしてよい唯一の設計資料（`設計書.md`）
  - **現役の運用資料**: 工程表・研究資料・憲章
  - **歴史資料（`archive/`）**: 旧アーキテクチャ資料・決定ログ。経緯の参照専用。**実装の根拠にしてはならない**

## 3点セット（まずここ）

| 知りたいこと | 資料 |
|---|---|
| どこに何が書いてあるか | `INDEX.md`（本書） |
| 設計の正（仕様のすべて） | `設計書.md` |
| 現在地・工程・次のアクション | `MILESTONE.md` |

※ architecture-reviewer の測定器は `憲章.md`（原典 `設計書.md` の従）。
