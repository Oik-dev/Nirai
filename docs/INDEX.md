最終更新: 2026-07-19（白紙実装 GO Wave 0: 設計書 v2・憲章縮小）

## 概要

本書とは、Serina の全ドキュメントの「どの資料のどの章に何が書いてあるか」を引くための索引である。

- 資料は3区分で管理する
  - **正典**: 実装・修正の根拠にしてよい唯一の設計資料（`設計書.md`）
  - **現役の運用資料**: 工程表・研究資料・憲章
  - **歴史資料（`archive/`）**: 決定ログのみ。経緯の参照専用。**実装の根拠にしてはならない**
