# マイルストーン更新手順

## 原則

- `docs/MILESTONE.md` は**中断復帰用の現在地のみ**。履歴を堆積させない（肥大化したら本skillの違反）。
- `docs/DECISIONS.md` は**決定ログ**。新しい順に日付見出しで追記し、既存エントリは書き換えない。

## 手順

1. **DECISIONS.md**: 先頭（`---` 区切りの直後）に `## YYYY-MM-DD 見出し` セクションを追記。内容は「何を決めたか＋理由＋根拠の所在（specs/へのリンク）」。
2. **MILESTONE.md**:
   - 「最終更新」と「現在フェーズ」を更新
   - 「📍 現在地」は完了項目を1行に圧縮（詳細は DECISIONS へ）
   - 「🎯 次のアクション」を次の1手に書き換える
3. 決定がスライス設計に影響する場合は `docs/specs/` の該当設計書にも反映し、変更箇所に日付を付す。
4. コミット: `docs: マイルストーン更新（<要旨>）`

※コード変更を含む節目では、コミット前に `completion-review` skill が未実施なら先に実施する。
