# マイルストーン更新手順

## 原則

- `docs/MILESTONE.md` は**中断復帰用の現在地のみ**。履歴を堆積させない（肥大化したら本skillの違反）。
- `docs/archive/DECISIONS.md` は**決定ログ**。新しい順に日付見出しで追記し、既存エントリは書き換えない。

## 手順

1. **DECISIONS.md**: 先頭（`---` 区切りの直後）に `## YYYY-MM-DD 見出し` セクションを追記。内容は「何を決めたか＋理由＋根拠の所在」。
2. **MILESTONE.md**:
   - 「最終更新」と「現在地」を更新
   - 完了した残作業は行ごと削除する（実装済みの設計はすべて `docs/設計書.md` へ。履歴は DECISIONS へ）
   - 「残作業」「検討中・保留」を次の実態に書き換える
3. 決定が設計に影響する場合は `docs/設計書.md`（正典）に反映する。正典には検討中・工程・レビュー痕跡を書かない（検討中は MILESTONE の「検討中・保留」へ）。
4. コミット: `docs: マイルストーン更新（<要旨>）`

※コード変更を含む節目では、コミット前に `completion-review` skill が未実施なら先に実施する。
