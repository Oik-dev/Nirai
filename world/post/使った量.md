# 使った量のメーター

郵便局が動いているときに **http://127.0.0.1:47800/usage** を開く。Holoの拡張の「使った量を見る」からも開ける（拡張の更新後は再読み込みする）。期間は日本時間で指定する。最初は今日を含む7日間。ページを開くか「集計する」を押したときだけ読み取り、住人を起こさない。

住人とGUI（Masterとの画面の会話）／CLI（郵便局からの仕事）ごと、日ごと、作業場ごとの量を表示する。量は入力・キャッシュの読み書き・出力を分け、比較用の重さも表示する。時間は起きてから止まるまでの延べ時間で、道具の待ち時間も含む。2人が10分ずつ働けば20分になる。

## 数え方

- Claudeはユーザーの `.claude/projects/<本物のNiraiのパスを変換した名前>/*.jsonl` の直下だけを読む。`claude-desktop`をGUI、`sdk-cli`をCLIとする。assistantのusageを`message.id`と`requestId`の組でまとめる。複数ブロックに分かれた出力は最大の数を採り、重複保存を二重計上しない。
- Codexは住人の `lifelog/codex-cli/<日本時間の日付>.jsonl` の `turn.completed.usage` をthreadごとに足す。入力にキャッシュ読みが含まれるので差し引き、出力に含まれる推論分は追加しない。時刻の記録がないため、量の日付は**目覚めを開始した日（保存ファイルの日付）**。
- 比較用の重さは、未キャッシュ入力×1＋キャッシュ書き込み×1.25＋キャッシュ読み×0.1＋出力×5。今回の依頼の物差しを両者へ同じように適用する。実際の請求額や契約の残量を表すものではない。
- 作業場は各住人の郵便のwake／stopと、wakeに含まれた手紙のworkから引く。複数の作業場がひとつの目覚めに含まれた場合は、共同の目覚めとして1回だけ数える。CLIの割り当てが分からない分は「割り当て不明」に残す。Codexは日ごとのwakeとthreadの数が合う場合だけ、開始順で対応させる。
- 時間は選んだ期間との重なりだけを数える。今の目覚めは途中までの暫定値。過去の終了記録が欠けた目覚めは時間に足さず、その件数を示す。GUIの会話時間は測っていない。Holoは郵便局から起きた時間だけを表示し、トークン量は未計測。

## 読み取れる範囲

Holoの量・Masterが使うCodexのGUI・Cursor・Serinaは未計測。Claude/CodexのCLIでも、終了前でまだusageが記録されていない出力は量に含まれない。ファイルの不完全な行や読み取り失敗は件数を表示する。合計は読み取れた分だけで、欠測をゼロと判断しない。診断の件数は、期間外も含む読み取り元全体の記録について示す。

会話・手紙・道具の出力の文章は参照せず、数・時刻・識別子・使い方・作業場名だけを取り出す。元のイデアや生ログを編集・移動せず、集計したコピーも保存しない。SerinaのイデアとClaudeの `lifelog/claude-code` は開かない。

同じ数をJSONで取得するには `world/` で実行する。

```powershell
npm run usage -- --from 2026-10-05 --to 2026-10-07
```

試験では `NIRAI_RESIDENTS` で使い捨ての住人置き場、`NIRAI_CLAUDE_PROJECT` で人工のClaude記録の置き場を指定できる。ページから読み取り元を指定することはできない。
