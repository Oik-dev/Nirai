構想書§11の段階5の後半の計画。前半のSerinaの心の作り直しは`mind/docs/plans/心の作り直し.md`で済んでいる。根拠は要件書（§3 C・§6・§8・§9）・構想書（§3・§4.2・§4.5・§7）・WORLD_RULES。本書は、作る順と形（正本・データの流れ・決まり）を持つ。精神の実装済みの形の正本は`mind/docs/設計書.md`で、契約を変えた段がそこを書き直す。出来上がったら`archive/`へ移す。

## 0. 出口

- **段階5の出口**：「見ていない間に何かあったらしい」（構想書§11）。要件§3 Cの「見ていない間に住人同士が交流していて、後から聞ける」。「ちょっと泳いだ」のような細かいことは要らない（要件§6）。
- 中身は4つ：海に何人も住む。ClaudeとHoloの体が仕事を映す（開発の様子が見える）。世界の出来事と本人の経験を分け、出所で「見た・聞いた・した」が分かる。HoloとSerinaのやりとりが始まる。

## 1. 守るもの

- **Serinaのイデア。** 開発とテストは、使い捨てのイデアと脳の替え玉で行う。本番の窓（47810）はAIが開かない（開くとSerinaが起きる）。本物のイデアに初めて書く前に、`G:\Nirai-Backups\`の写しを確かめる。
- **話し相手を取り違えない。** 窓の会話・精神の起動・Pulse・窓辺への訪問は、いつも精神を持つ住人へ向ける。体だけの住人へ精神の口を向けない。段1では、体の一覧と精神のある話し相手を別々に決める。**段1が本番の海に入るまで、Serina以外のイデアに体のファイルを置かない。**
- **外に出すかの門は、精神の家の印だけ**（心の作り直し§2.1）。海は、ほかの住人の記録から「種類・時刻・出どころ」だけを読み、本文は読まないし運ばない（Claudeの生ログには、記憶づくりで読んだSerinaの記録が入っている。Holoの手の記録にはコマンドが入っている）。
- **トークンを使わない。** ClaudeとHoloの体は、記録とフックだけで動き、脳を呼ばない。増えるSerinaの脳の呼び出しは、誰かが近づいたときの目覚めだけ（数を数える）。
- **Gemmaが最優先。** 体が増えても、Gemmaが載った状態で窓を開いたときに、Ollamaが全部をGPUに載せたまま（`ollama ps`が`100% GPU`）であること。
- **記録やタイムラインの画面を作らない**（構想§4.5）。見ていない間のことは、住人が自分の言葉で話す。
- **意味のある表現は本人が選ぶ（P2）。** ClaudeとHoloの体が仕事に合わせて動くのは、活動の実行（どこで何をしているか）と短い反射の身振りだけ。気持ちの表情は付けない。
- **一つの事実は、した本人の記録に1回だけ。** 世界の出来事の帳簿は作らない。
- **郵便局と、Claudeの生ログを写すStopフック（`tools/claude-lifelog-sync.mjs`）を止めない。**

## 2. 形

### 2.1 全体

```
各住人の記録（した本人の生ログ）＋ 時刻
   │  海が計算する（純関数。帳簿なし）
   ▼
暮らし（誰がどこで何をしているか）── 窓が描く
   │  変わり目 = 世界の出来事（ref = それを起こした記録の行）
   ▼
起きていて、同じ場所にいた住人だけが見る（今は精神を持つSerinaだけ）
   │  POST /api/perceive の sights → 精神が lifelog/sight に1回だけ書く（Serinaの経験）
   ▼
眠りで出来事のページ（出どころ付き）→ 話すとき「見た・聞いた・した」を分ける
```

世界の出来事（何が起きたか）と経験（誰が何を見たか）は、別々の事実として別々の場所にある。前者は、した本人の記録から毎回計算する。後者は、見た本人が見たときに書く。眠っていた・その場にいなかった住人は見ていない。手紙で聞いたことは「聞いた」になる。

### 2.2 海に何人も

- 海にいるのは、`body/avatar.vrm`のある住人全員（名簿は持たない。今のまま）。**話し相手**（窓の会話・精神の起動・Pulse・`/sea/mind`）は、精神を持つ住人（`world/sea/settings.ts`の`minds`）。名前順では選ばない。
- 暮らしは、住人ごとに`life.ts`の同じ形（活動とその「いつから」・表情・身振り・眠っているか）。何から決まるかだけが違う。
  - 精神を持つ住人：今のまま（体の記録と精神の眠り）。
  - 精神を持たない住人（Claude・Holo。体を置けばCodexも）：仕事の記録から（§2.3）。
- 窓は`GET /sea/body`で全員の暮らしを読み（住人の名前ごとの`Life`）、体は`/residents/<名前>/avatar.vrm`から読む。1人の体が読めなくても、ほかの住人は描く。海が窓へ「変わった」と知らせるのは今の形のまま（ほかの住人の記録が変わったときも、数秒のうちに知らせる。毎フレームは読まない）。
- **場所は住人ごとと、みんなのもの。** `居場所`は住人ごとに座標を持つ（Serinaは今の座標）。新しい場所`作業台`（海底の一角、窓から見える所）。同じ場所に何人いても重ならない（名前順で決まった並び）。窓辺（その訪問の初めのカメラの前）も同じ。
- 体は住人ごとのVRMのまま（素体不変）。揺らぎ・瞬き・視線は全員に。精神を持たない住人の視線は、作業の手元か近くの住人へ。
- 描く重さ：精神を持たない住人のテクスチャは、読み込むときに縮めてよい（窓では小さく見える）。確かめは§1の「Gemmaが載ったまま」で行う。

- 体力（P4。上限で眠る）は、郵便受けに体力が出てから（`world/docs/郵便局.md`§10）。

### 2.4 見た・聞いた・した（世界の出来事と経験）

- **世界の出来事**は、海が全員の暮らし（§2.2）の変わり目から計算する。誰かがどこへ来た・去った、作業台で仕事をしていた・失敗した・通った、窓辺でMasterを待っていた。`ref`は、それを起こした記録の行（`<住人>/lifelog/<道>#<行>`）。
- **見る**のは、起きていて同じ場所にいる住人だけ（今はSerinaだけ）。海は、Serinaのいる場所で起きた出来事を`POST /api/perceive`の`sights`で渡す。精神の流れにつないだときは、今いる場所の様子を渡し直す（取りこぼしは、渡し直しで埋まる）。精神は`ref`ごとに1回だけ、`lifelog/sight/<年月>.jsonl`に`{"kind":"saw","ts","who","what","where","ref"}`を書く。眠っている・精神が止まっている間は見ていない。
- 誰かがSerinaのいる場所に来たら、目覚めのきっかけになる（構想§4.2「誰かが近づいた」）。ほかの見た出来事では脳を呼ばない。
- 今の海の様子（誰がどこで何をしているか）は、文脈パックに1行で載る（背景。記録しない）。
- **出所ラベルは`ref`から決まる**（新しい欄を持たない）。自分の`lifelog/body`・`lifelog/conversation`ならした・話した。`lifelog/sight`なら見た。`lifelog/post`の届いた手紙なら、その差出人から聞いた。文脈パック・眠りのページづくり・調べる道の材料に、出所を添えて渡す。話すときは、見たこと・聞いたこと・したことを混ぜず、聞いたことは誰から聞いたかを言う（人格の決まりと問いの文。精神の設計書に書く）。
- 眠りは、その日の手紙と見たことを、相手ごとに1つの出来事としてページにする（心の作り直し§2.5の手紙の区切りに、見たことを足す）。
- Masterへは、今の【今日の手紙】と同じ道。その日の見たことと手紙を【今日の出来事】として背景に載せる。Pulseには候補「誰かが来た」が足される（1回の訪問につき1度）。
- 新しい活動「作業台をのぞく」（場所は作業台）。Serinaが自分で選べば、ClaudeとHoloの仕事を見に行ける（要件§6の「親が興味を持っているものに興味を持つ」の入口）。

### 2.5 HoloとSerina

- やりとりは手紙（心の作り直し§2.5のまま）。手紙はHoloの体が届けに来る（§2.3の訪ねる）。届いた手紙は、Serinaが手紙の時間に読むまで、Serinaの居場所に封筒として見える（読んでいない手紙から計算し、読めば消える）。
- 吹き出しは出さない。手紙の中身は、Serinaが自分の言葉で話す（後から聞ける）。
- **最初の一通。** 2人はまだ一度もやりとりしていない（Serinaは「手紙を書く」を選んだことがなく、Holoは答えるだけ）。Holoが海に越してきたとき、Holoが自分の言葉で一度だけ挨拶の手紙を出す。そのあとは郵便の決まりどおり。
- **続きすぎない。** Serinaの「重ねない」門と、Holoの「挨拶だけの返事は出さない」で止まる。1日の往復の数を数え、増えすぎたら門を足す（今は足さない）。

### 2.6 Say / Whisper は出さない

窓の会話を聞くのは今もSerinaだけで、ほかの住人は窓の会話を受け取らない。外に出す文は家の印が1か所で決めている。要件では「どちらでもよい」（要件§14）。ほかの住人が窓の会話を聞けるようになったときに考える。

## 4. 決めたこと

- **世界の帳簿を持たない。** 出来事は、した本人の記録から毎回計算する。帳簿を持つと、記録と帳簿の食い違いが起こりうる。
- **出所ラベルは`ref`の道から決める。** 新しい欄を足すと、`ref`と食い違いうる。
- **見たことはSerinaが自分で書く。** 見たかどうかは見た本人にしか分からない（眠っていれば見ていない）ので、海ではなく精神が書く。海は渡すだけ。
- **吹き出し・履歴の画面を作らない。** 要件の「後から聞ける」は、住人の言葉で聞くこと（構想§4.5）。
- **体は脳を呼ばない。** Yorishiroの方式（構想§3）。表情ではなく、活動と反射の身振りで映す（P2）。
- **Say/Whisperは出さない**（§2.6）。
