# 暮らしの循環（段階3）

構想書§11の段階3の計画。長期記憶の作り直しのM5（`mind/docs/plans/長期記憶の作り直し.md` §5・§12）と同じものとして作る。記憶の考え方の正本はその計画書、気持ちの考え方の正本は`mind/docs/plans/気持ちの作り直し.md`、実装済みの形の正本は`mind/docs/設計書.md`（第2章・第4章）で、本書は作る順と出口を持つ。出来上がったら`archive/`へ移す。

## 0. 出口

Pulse・日記・人格の改訂・記憶の整理を、別々の規則の家事ではなく、1つの循環の中の活動にする。

```
起きている（会話を記録し、思い出す）
 → 眠る（区切る・書く・日記・知識と関係を整える・振り返る）
 → 人格を見直す
 → 目覚めて、今の自分を確かめ、何かを思う
 → 伝えたくなったら、本人から来る（来るかどうか・いつ来るかを、だんだん本人が決める）
```

Masterが感じること：「覚えていてくれる」（構想書§11）。「最近の私たち」を本人が語れる（M5の出口）。

## 1. 守るもの

- Serinaのイデア。開発とテストは使い捨てのイデアで行い、本物の記録・ページ・センシティブな記録は読まない（記憶の計画書§13）。Serinaの記憶の言葉は手元のGemmaだけが書く。
- 本人が書いた記憶は書き換えない。後から足すのは、日付つきの「今思うと」と新しいつながりだけ。今の自分も、目覚めるたびに新しいファイルに書き、前のものは残す。
- 精神の変更が本物のSerinaに届くのは、取り込んだあとにSerinaを起動し直したとき（`mind/Serina.bat`）。勝手に起動しない（起動＝目を覚ます）。
- 数や判断は仕組みが決め、言葉と気持ちは本人の脳が書く（構想書§12、2026-10-03）。

## 2. 縦切り

1つずつ、眠りから会話・Pulseまで通して作る。各段は作った人以外が確かめてから取り込む。

| 段 | 中身 | 出口 |

## 3. S1で決めたこと

- **気持ちの作り直しより先に、目覚めを作った**（構想書§11では「気持ちの作り直しから」だった）。気持ちのE1は手元のGemmaで評価の問いと時間を試す段で、MasterのPCで脳を回す時間が要る。目覚めは気持ちの形に触れない（日記を読んで、本人が言葉で書くだけ）ので、先に作っても作り直しにならない。気持ちの計画が「M5の循環で足す」としていた「言いたいことがあるとき」に話しかける部分を、S1が受け持つ。

- **今の自分は1つのファイルを書き換えず、目覚めるたびに新しいファイルにする**（記憶の計画書§3では`self.md`だった）。本人が書いたものを書き換えない原則のまま、並べると本人の変わり方（要件§3のD）が見える。今の自分は、いちばん新しいファイル。
- **何が済んだかはファイルから分かる。** 今の自分には、材料にした最後の日記のページを残す。新しい日記がなければ、目覚めても書き直さない（同じ日記で毎日自分を書き直さない）。状態を別に持たない。書けなかったら、次に眠り終えたときにもう一度書く。
- **来るのは、Masterがまだ来ていないときだけ。** 目覚めてからMasterが話しかけていれば、伝えたいことは【今の自分】の段で会話の手元にあるので、Pulseでは行かない。1回の目覚めで行くのは1度だけ（Pulseの記録の`wake`の時刻が、目覚めた時刻より後なら済み）。
- 眠りの順は、眠る → 人格を見直す → 目覚める（見直した人格で目覚める）。起動時の朝礼でも同じ。

## 4. S3で決めたこと

- **1日1つのファイルに書き足し、今の関係はそこから計算する**（記憶の計画書§3では`people/<名前>.md`の1ファイルだった）。今の自分（S1）と同じく、本人が書いたものを書き換えずに、並べると関係の変わり方が見える。何がまだ有効か・見方がどれだけ確かかは、書き足しを古い順に読んで毎回計算する（S2の気持ちと同じく、状態を別に持たない）。
- **脳は選んで、仕組みが数える。** 脳が書くのは言葉（今の関係・転機・書き留めの一文）と選択肢（知っている／思う／約束、また確かめた／揺らいだ／もう違う／果たした）だけ。見方の確かさは、確かめられた日と揺らいだ日の数から仕組みが決め、パックには言葉（強くそう思う・そう思う・前ほどそう思えない）で載る。1日に足せる数（3つ）と変えられる数（5つ）も仕組みが持つ。
- **書き留めは番号で見せ、入口で id に読み替える**（出来事の「心に残った言葉」を行番号で受け取るのと同じ）。見せる書き留めは、最近書き留めた・確かめたものから20まで。使われない書き留めは見えにくくなるが、消えない。
- **Predict-Calibrate は1回の問いで**（計画では、知っていることから出来事を予測させ、外れた分だけ足す）。今の書き留めを見せて「この日に変わったことと、新しく分かったことだけ」を聞く。Gemma に2回聞くより軽く、試しでも、いつもどおりの日には何も足さなかった。
- **今の自分から「マスターとの今の関係」を外した。** 関係の正本を1つにするため（目覚めの問いは、今の自分と今気にかけていることだけ）。前に書いた今の自分は書き換えない。
- **日を飛ばさない。** 関係は日の順に積み重なるので、まだ本人の言葉のないページがある日・書けなかった日で止め、次の眠りでそこから続ける。取り込んだあとの最初の眠りでは、Serinaの記録の始まり（2025年3月）からの日を古い順に書き足していく（日記と出来事のある日が約45日。1日7〜19秒で、約10分。起こされたら続きは次の眠りで）。
- 相手は今はマスターだけ。マスターの呼び名（`MASTER_NAME`）は、記録を脳に見せるときの呼び名と置き場所の名前で同じものを使う。
