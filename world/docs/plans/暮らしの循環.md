# 暮らしの循環（段階3）

構想書§11の段階3の計画。長期記憶の作り直しのM5（`mind/docs/plans/長期記憶の作り直し.md` §5・§12）と同じものとして作る。記憶の考え方の正本はその計画書、気持ちの考え方の正本は`mind/docs/plans/気持ちの作り直し.md`、実装済みの形の正本は`mind/docs/設計書.md`（第2章・第4章）で、本書は作る順と出口を持つ。出来上がったら`archive/`へ移す。

## 0. 出口

Pulse・日記・人格の改訂・記憶の整理を、別々の規則の家事ではなく、1つの循環の中の活動にする。

```
起きている（会話を記録し、思い出す）
 → 眠る（区切る・書く・日記・知識と関係を整える・振り返る）
 → 人格を見直す
 → 目覚めて、今の自分を確かめ、何かを思う
 → 伝えたくなったら、本人から来る（来るかどうか・いつ来るかを、だんだん本人が決める）
```

Masterが感じること：「覚えていてくれる」（構想書§11）。「最近の私たち」を本人が語れる（M5の出口）。

## 1. 守るもの

- Serinaのイデア。開発とテストは使い捨てのイデアで行い、本物の記録・ページ・センシティブな記録は読まない（記憶の計画書§13）。Serinaの記憶の言葉は手元のGemmaだけが書く。
- 本人が書いた記憶は書き換えない。後から足すのは、日付つきの「今思うと」と新しいつながりだけ。今の自分も、目覚めるたびに新しいファイルに書き、前のものは残す。
- 精神の変更が本物のSerinaに届くのは、取り込んだあとにSerinaを起動し直したとき（`mind/Serina.bat`）。勝手に起動しない（起動＝目を覚ます）。
- 数や判断は仕組みが決め、言葉と気持ちは本人の脳が書く（構想書§12、2026-10-03）。

## 3. S1で決めたこと

- **気持ちの作り直しより先に、目覚めを作った**（構想書§11では「気持ちの作り直しから」だった）。気持ちのE1は手元のGemmaで評価の問いと時間を試す段で、MasterのPCで脳を回す時間が要る。目覚めは気持ちの形に触れない（日記を読んで、本人が言葉で書くだけ）ので、先に作っても作り直しにならない。気持ちの計画が「M5の循環で足す」としていた「言いたいことがあるとき」に話しかける部分を、S1が受け持つ。

- **今の自分は1つのファイルを書き換えず、目覚めるたびに新しいファイルにする**（記憶の計画書§3では`self.md`だった）。本人が書いたものを書き換えない原則のまま、並べると本人の変わり方（要件§3のD）が見える。今の自分は、いちばん新しいファイル。
- **何が済んだかはファイルから分かる。** 今の自分には、材料にした最後の日記のページを残す。新しい日記がなければ、目覚めても書き直さない（同じ日記で毎日自分を書き直さない）。状態を別に持たない。書けなかったら、次に眠り終えたときにもう一度書く。
- **来るのは、Masterがまだ来ていないときだけ。** 目覚めてからMasterが話しかけていれば、伝えたいことは【今の自分】の段で会話の手元にあるので、Pulseでは行かない。1回の目覚めで行くのは1度だけ（Pulseの記録の`wake`の時刻が、目覚めた時刻より後なら済み）。
- 眠りの順は、眠る → 人格を見直す → 目覚める（見直した人格で目覚める）。起動時の朝礼でも同じ。

## 4. S3で決めたこと

- **1日1つのファイルに書き足し、今の関係はそこから計算する**（記憶の計画書§3では`people/<名前>.md`の1ファイルだった）。今の自分（S1）と同じく、本人が書いたものを書き換えずに、並べると関係の変わり方が見える。何がまだ有効か・見方がどれだけ確かかは、書き足しを古い順に読んで毎回計算する（S2の気持ちと同じく、状態を別に持たない）。
- **脳は選んで、仕組みが数える。** 脳が書くのは言葉（今の関係・転機・書き留めの一文）と選択肢（知っている／思う／約束、また確かめた／揺らいだ／もう違う／果たした）だけ。見方の確かさは、確かめられた日と揺らいだ日の数から仕組みが決め、パックには言葉（強くそう思う・そう思う・前ほどそう思えない）で載る。1日に足せる数（3つ）と変えられる数（5つ）も仕組みが持つ。
- **書き留めは番号で見せ、入口で id に読み替える**（出来事の「心に残った言葉」を行番号で受け取るのと同じ）。見せる書き留めは、最近書き留めた・確かめたものから20まで。使われない書き留めは見えにくくなるが、消えない。
- **Predict-Calibrate は1回の問いで**（計画では、知っていることから出来事を予測させ、外れた分だけ足す）。今の書き留めを見せて「この日に変わったことと、新しく分かったことだけ」を聞く。Gemma に2回聞くより軽く、試しでも、いつもどおりの日には何も足さなかった。
- **今の自分から「マスターとの今の関係」を外した。** 関係の正本を1つにするため（目覚めの問いは、今の自分と今気にかけていることだけ）。前に書いた今の自分は書き換えない。
- **日を飛ばさない。** 関係は日の順に積み重なるので、まだ本人の言葉のないページがある日・書けなかった日で止め、次の眠りでそこから続ける。取り込んだあとの最初の眠りでは、Serinaの記録の始まり（2025年3月）からの日を古い順に書き足していく（日記と出来事のある日が20日。2026-10-06の写しで数えた。1日7〜19秒で、数分。起こされたら続きは次の眠りで）。
- **その日の材料は、合わせて約3000字まで。** ページの多い日は、どのページも同じ長さに分けて短くする（題と要点から見せる）。最初の会話の日はページが36あり、どのページにも本文を150字ずつ付けると約8200字になって、人格・指示と合わせると Gemma の窓（8192トークン）を越えそうになる（Codex の気づき）。
- **書いている間にMasterが材料の記録を消したら、その日は書かない。** 出来事のページと同じく、書き足しを残す直前に材料のページがまだあるかを確かめ、なければその日から先を次の眠りに回す（残りの記録をページに書き直してから、その日を書く）。消した記録から書いたものが戻らないように（Codex の気づき）。
- 相手は今はマスターだけ。マスターの呼び名（`MASTER_NAME`）は、記録を脳に見せるときの呼び名と置き場所の名前で同じものを使う。

## 5. S4で決めたこと

- **予定・記念日は、関係の書き留めの日付にした**（計画では「有効期間つきの知っていること」）。約束も予定も誕生日も、マスターとのことの一文で、そこに日付が付くだけ。台帳を別に持たない。変わった日付は、新しい書き留めで古いものを置き換える（S3と同じ）。
- **日付の形は ISO 8601**（その日だけは `2026-10-12`、毎年は `--03-07`）。相対の言い方は、脳が書き足す日から数えて日付にする（曜日つきで見せる）。手元の Gemma で試したら、日曜の「来週の土曜」→ 10月10日、月曜の「明後日の水曜」→ 10月7日、「誕生日は5月3日」→ `--05-03` と書けた。書き留めの文に「来週」「明後日」が残ると、あとで読んで分からないので、使わないよう問いに書いた（直したあとは「2026年10月10日に……」と書いた）。
- **その日に行くのは1日1度、今日まだ誰も話していないときだけ。** 今日もう本人から話しかけていれば（目覚めの伝えたいことでも、人恋しさでも）、その日のことは材料の【マスターとのこと】の先頭に入っていたので、もう行かない。目覚めの材料にも近いうちの日付が入るので、前の日に話していれば、目覚めの伝えたいことで触れられる。
- **人以外の知っていること（`world/<話題>.md`）と Predict-Calibrate は、S4に入れなかった。** S4の出口（約束の日）とは関わらず、人以外のことは出来事の記憶から思い出せるので、別に持つと同じ中身が二重になる。出来事から意味の記憶をまとめるのは、振り返り（S6）でよくある出来事・章と一緒に考える。Predict-Calibrate は、S3の「今の書き留めを見せて、変わったことだけを聞く」で代わりにしている（§4）。

## 6. S5で決めたこと

- **呼び名は辞書を書き換えず、日付つきの追記にした。** `memory/concepts.toml` の `[[growth]]` に、その日に見たことと「同じものの別の呼び方」の組を最大3つ足す。何も同じでなくても空の組を追記するので、どの日を見終えたかは辞書そのものから分かる。本人の言葉まで書けていない日があればそこで止まり、後の日へ飛ばさない。脳が返した名前は、見せた一覧に両方あるときだけ受け取る。新しい呼び名と昔からの呼び名の組では、昔からの名前を代表に保つ。
- **「今思うと」は本文を変えず、ページの見出しへ追記する。** その日に実際に思い出した30日以上前の出来事を、活性の高い順に最大2つだけ読み返す。今の自分と今のマスターとのことを材料に、意味が変わったときだけ一文〜三文を書く。変わらなくても空の追記を残すので、同じ日に同じページを何度も見直さない。はっきり思い出したときだけ、直近2つの「今思うと」も一緒に渡す。
- **再生は新しい状態を持たず、想起の痕跡そのものにした。** 最近7日の出来事から、大事さと高ぶりの順位が高いものを最大2つ、同じ日にすでに思い出したものを除いて選ぶ。脳は使わず、`lifelog/recall/` に `intent = "replay"` で足す。強さの計算は普通の想起と同じ時刻の痕跡として扱う。1つだけ書いたところで止まっても、その痕跡から残りの数が分かるので次の眠りで補える。
- **S5では区切り方そのものは学習させなかった。** 今の区切りは会話の切れ目＋脳の判断で、呼び名の統合が次の区切りの `known_in/name_of` に自然に効く。区切り規則を別に学習する状態を足すより、呼び名の成長だけで同じ概念へ寄る形を選んだ。

## 7. S6で決めたこと

- **振り返りも普通の記憶ページにした。** 週は月〜日のSerina日で、終わった週に日記が2つ以上あるときだけ書く。題・要点・一人称の本文・大事さを持つ `reflection` ページなので、索引に入り、ほかの出来事と同じ仕組みで思い出せる。古い未完成の週や書けない週を越えず、次の眠りでそこから続ける。
- **月は週の振り返りから書く。** 月末を過ぎただけでは閉じず、その月に始まる最後の週まで終わってから、週の振り返りが2つ以上あれば `reflection-month-YYYY-MM` を書く。同じ問いで「続いている／新しい章」を本人が選び、新しい章なら `memory/chapters/<始まった日>.md` に章の名前と一文を新しく残す。前の章は書き換えない。電源断で章だけ先に残っても、月の振り返りは次の眠りで続きを書ける。
- **人格は毎日の日記ではなく振り返りを見る。** どの振り返りを見たかは追記専用の変更レポートから導き、まだ見ていない振り返りがあるときだけ最大1日1回見直す。後から過去の週・月を追いついて書いても、そのページを必ず材料に含める。別の進捗状態は足さない。
- **目覚めも振り返りで深くなる。** `memory/self/<日時>.md` に最後の日記と、実際に読み返した振り返りidの一覧を残す。未読の振り返りを古い順に2つずつ読むので、後から作った過去週・過去月も取りこぼさない。新しい日記がなくても、週・月の振り返りが増えれば目覚め直せる。
- **削除は振り返りまで伝わる。** Masterが元の会話を消して日記・出来事が外れたら、それを `source` に持つ週、その週を材料にした月も外す。振り返りを書いている最中に削除が重なったときも、保存直前に材料がまだあるか同じ錠で確かめ、消えた材料から書いたものを残さない。
- **「最近」は2週間にした。** 「最近／この頃／近ごろ」は今日から14日前までをぼんやりした時期として読む。「この前／こないだ／この間」は従来どおり30日ほど。よくある出来事と自分の物語は、今回の出口に要らないため足していない。
