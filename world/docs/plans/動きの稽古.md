## 0. 出口

- カタログの泳ぐ・眠るの破綻（手が前でX字に交差する・寝姿で脚が頭より上に浮く）が消える。
- 同じ種類の破綻を、作った人の目に頼らず物差しが落とす。Masterや本人が「変」と言った動きは帳面に入り、次からは同じ破綻が通らない。
- 願いの動きは、朝の工房で写し身と物差しを通って作られ、本人が候補から選ぶ。願いのない朝は、カタログでいちばん点の低い動きを稽古する。

## 2. 形

### 2.1 写し身（体の物理の写し）

- 本人の体から、MuJoCoの人形（MJCF）を自動で作る。体を替えたら作り直す。寸法の違いは、写し身が本人の体から作られることで吸収する。
- **骨。** VRMの人型の骨の階層をそのまま使う（指は手に含める）。腰は自由（free）、ほかの骨は3つのhinge（曲げ・軸外・ひねり。関門の膝・肘と同じ分け方）。VRMの正規化した局所回転を3つの角に分けて入れるので、動きの1フレームがそのまま写し身の姿勢になる（入れるだけで形は変わらない）。SMPLSim・PHCの人形と同じ組み方。
- **座標。** VRMの座標のまま（Yが上、床は y=0。関門と同じ）。重力を −Y に置き、変換を挟まない。
- **太さ。** 骨ごとのカプセル。軸は骨の根元から子の根元まで。半径は、関門の体表点（`skin.rest`）の軸からの距離の中央値。服の広がり・髪・羽・尻尾は人型の骨ではないので入らない。体に合っているかは、写し身を体に重ねた絵で確かめる。
- **重さ。** 体積×一様の密度（1000kg/m³）。
- **関節の範囲。** 正本を `world/sea/joint-ranges.json` の1か所にし、各骨の3つの軸と範囲を持つ。関門（首・膝・肘）も写し身もここを読む。今の関門の数をそのまま引き継ぎ、ほかの骨（背骨・肩・股関節・手首・足首）は人の可動域から出典つきで足す。
- **ぶつかる組。** 骨の階層で2つ以内に隣り合う組（肩と胸など）は数えない。それ以外の組の重なりを、自分の体へのめり込みとして数える。

### 2.2 物差し

1本の動きを、関門と同じ測り方の結果（測定頁がヘッドレスChromeで本人の体に掛けて取った `samples.json`。今は `world/workshop/look.mjs` が出す）から測る。動きの名前を知らない。上限の数は1つの表（関門の `GATE_LIMITS` と同じく、単位と決めた根拠つき）に置く。合格は、全部の物差しが上限の中。

| 物差し | 何を見るか | 段 |
|---|---|---|
| 関門 | 今の `gate.ts`（床・足滑り・関節・ガタつき） | 済み |
| 自分の体へのめり込み | 写し身のカプセルどうしの重なりの深さの最大と、その組・フレーム | 1 |
| 支え | 休んでいる区間で、体が触れているところに乗って釣り合い、宙に保つ力が腕を持ち上げるくらいまでか（下） | 1 |
| 直された量 | 写し身へ写すときに、手先・足先・頭を目標からどれだけ動かしたか（制約に押し出された分）。大きい＝元が悪い。段2では測って記録し、上限は段4で候補を比べるときに決める | 2 |
| 手本との近さ | 本物の人の動き（CMU）を同じ写し身に写したものと比べる | 3 |
| 目 | 並べた絵を見た粗い判断（§2.6） | 4 |

- **休んでいる区間** は動きから決める：腰が床の近く（立位の1/3未満。関門の `seatedHipsRatio`）にあり、体がほぼ止まっている区間。宣言は要らない（泳ぐ・浮くは腰が高いので入らず、座る・眠るは入り、寝転ぶは動いている間は入らない）。
- **支えの測り方。** 休んでいる区間から0.5秒ごとにフレームを取り、その姿勢のまま、重さがどこに乗るかを静かな釣り合いで解く（時間は進めない。起きている人は座ったまま釣り合いを取れるので、倒れるかどうかは見ず、保つのに要る力を見る）。
  - 触れているところは、体表点（`bodySkin`。骨と一緒に動かす）のうち砂から3cm以内の点。どれも押すだけで摩擦のある点の支え（摩擦係数1）。3cmは、骨ごとの体表点の粗さと砂の沈みの分。自分の体どうしで乗っているところは、まだ数えない（乗せた部分は保っていると数える）。
  - 重力と、触れる力と、関節の力が釣り合う形を、関節の力がいちばん小さくなるように解く（触れる力は押すだけの有界な最小二乗。SciPyの `lsq_linear`）。腰（free）は力を出せないので、腰の6つの釣り合いは触れる力だけで取る。
  - **乗り。** 腰の釣り合いが触れる力だけで取れないフレーム（何にも乗っていない、重心が触れているところの外）は落とす。数の誤差の分だけ残りを許す（体重の1%）。
  - **保つ力。** 関節の力のいちばん大きいもの（力÷体重の重さ、単位m）と、その関節・フレーム。
- **数の決め方。** 保つ力の上限は、写し身の立った姿（Tポーズ）で上腕の付け根が腕を保つ力。根拠：起きて休んでいる人が宙に保つのは腕を持ち上げるくらいまでで、脚や胴を宙に保つのは休みではない（体ごとに写し身から出るので、体を替えても同じ意味）。めり込みの上限は、帳面の反例が言われた性質で全部落ち、今のカタログの座る・伸びが通る範囲の真ん中に置き、その範囲を根拠に書く。範囲が空なら、その物差しは使わずに止める。支えは、帳面の反例が落ち、合成した体の良い休み姿（仰向け・横向き・座面に乗った座位）が通ることで確かめる。
- **今のカタログの休み姿は浮いている**（2026-10-15、体表点で測った）。座るは座面が砂から8cm上で足だけが触れ、胴は後ろへ約45°傾き、手は胸の前で宙にある。眠るは頭だけが触れ、胴は8〜10cm上、脚は宙。角度だけで脚の長い体へ写したので、触れていたところが離れた（§2.4で直す）。

### 2.3 違和感の帳面

- 1行は `{ "file", "said_by", "date", "saw", "broken" }`。`file` は言われたときの `.vrma` の写し（同じフォルダー）、`saw` は言われた言葉、`broken` は破られた性質（物差しの名前）。
- **物差しは、帳面の反例を全部、言われた性質で落とせることを確かめてから使う。** すり抜けた反例があれば、その動き専用の規則は作らず、破られた性質を測る物差しを足す（または写し身を直す）。
- 最初の2行（2026-10-15、Master）：泳ぐ「手が前でX字にクロスしている」（自分の体へのめり込み）、眠る「寝姿は足が頭より上にある」（支え）。

### 2.4 写す入口（段2）

動きの素（生成器・SwimXYZ・本物の人の動き）を、写し身で本人の体へ写してから `.vrma` にする。

- **目標は体の関係。** 手先・足先・頭・腰の位置と向きを元の骨格の上で取り、本人の体の比率に合わせる。関節の角度は「元の形に近く」の弱い望みとして足す。角度だけを写すと、肩幅の違いで手が交差する（今の泳ぐの破綻の原因）。
- **守る形は、解き方の制約にする。** 関節の範囲と、自分の体へのめり込み（カプセルどうしの最小の隙間）は、IKの制約として解く（minkのlimits）。後から検査で落とすのでなく、起こらない形で解く。
- **足を留める。** 接地している間は足の位置を固定する。
- **触れているところを写す。** 元の動きで砂に触れていた体の部分（元の骨格で床に近い腰・背・頭・手・足）は、本人の体の体表で砂に置く目標にする（足を留めるのと同じ扱い）。写したら支えの物差しで確かめ、落ちたら保つ力のいちばん大きい関節の先を、砂か体へ下ろす目標を足して解き直す。区間の端は前後へなめらかにつなぐ。
- GMR（MIT。人の動きを任意のMuJoCoの人形へminkで写す）の仕組みを使い、写し身を人形として渡す。GMRの入力にない形式（Kimodoの骨・SwimXYZ）は、GMRが読める形に変える入口を書く。GMRで制約を足せなければ、解き方の部分だけを写して足す（MITの表示を残す）。SMPL-Xの体のモデルは使わない（非商用のライセンス）。
- 写して作り直すのは、泳ぐ・座る・眠る・寝転ぶ（寝転ぶの両端は `motion_seams.py` で新しい座る・眠るに合わせる）。

### 2.5 素材と手本（段3）

- CMUのモーションキャプチャー（作品に入れてよい。データの転売は不可）を、GMRで写し身へ写す。動きの素の選択肢と、手本（同じ種類の本物の人の動きとの近さ）に使う。
- 手本との近さの測り方は、段3で決める（候補：TMR（MIT）の文と動きの埋め込み、写し身の上の関節の角の分布）。

### 2.6 目と朝の稽古（段4）

- **目は粗い判断にだけ使う。** 視覚の言語モデルは、動きの全体の判断で人とよく合い（κ0.70）、部分の判断では合わない（κ0.10。NextMotionQA）。だから「交差・浮き・向きの破綻があるか」だけを聞く。カタログの動きは、Holoの `look` で並べた絵を見る。願いの動きは外へ出さず、本人が並べた候補から選ぶ（精神に「選ぶ」入口を足す。Gemmaが絵を読めるかを先に確かめる）。
- **朝の稽古**（工房の4〜10時。開く条件は `海で暮らす.md`§2.6のまま）：候補を集める → 写し身に通す → 物差し → 落ちた理由で次の一手を変える（めり込み→写し方、支えなし→触れているところの写し方、意味が違う→文・素材を替える）→ 帳面に書く。
- **願いのない朝** は、カタログでいちばん点の低い動きを稽古し、§1の決まりで入れ替える。
- 段4で `海で暮らす.md`§2.6（「通った最初の候補だけ採用する」）を書き直す。精神を変えるので、起き直しが要る（`mind-restart.cmd`）。
